# 1.1.3 生成器与迭代器

> **机器人视觉定位**：生成器是**流式处理视频帧**的利器——逐帧读取不爆内存。当你需要处理一个 10GB 的视频数据集时，用 `yield` 逐帧产出比一次性加载到内存靠谱得多。

## 2. 生成器：按需产出的迭代器 ⭐⭐⭐

### 2.1 `yield` 关键字

```python
def frame_generator(video_path: str):
    """逐帧读取视频——不一次性加载所有帧到内存"""
    import cv2
    cap = cv2.VideoCapture(video_path)
    total = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    count = 0
    
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        count += 1
        print(f"进度: {count}/{total}", end="\r")
        yield frame  # 产出当前帧，暂停执行
    
    cap.release()
    print(f"\n处理完成，共 {count} 帧")

# 使用——逐帧处理，内存始终只有一帧
for frame in frame_generator("road_video.mp4"):
    # 对当前帧做检测
    detections = model(frame)
    # 处理完后自动进入下一帧（不会积累内存）
```

### 2.2 生成器表达式

```python
# 列表推导式 → 一次性生成全部
all_boxes = [detect(frame) for frame in frames]  # 占用大量内存

# 生成器表达式 → 边检测边产出
all_boxes = (detect(frame) for frame in frames)  # 惰性求值

# 需要时再取
first_box = next(all_boxes)
second_box = next(all_boxes)
```

## 3. 视觉中的典型应用

### 3.1 视频帧流式处理

```python
import cv2
from typing import Generator, Tuple
import numpy as np

def read_video_stream(
    path: str,
    skip: int = 0          # 跳帧数
) -> Generator[Tuple[int, np.ndarray], None, None]:
    """
    流式读取视频帧
    
    Args:
        path: 视频文件路径
        skip: 每隔 skip 帧产出一帧（0=全部）
    
    Yields:
        (frame_index, frame) 元组
    """
    cap = cv2.VideoCapture(path)
    frame_idx = 0
    
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        
        if skip == 0 or frame_idx % (skip + 1) == 0:
            yield frame_idx, frame
        
        frame_idx += 1
    
    cap.release()

# 使用——处理 100000 帧视频，内存占用始终固定
for idx, frame in read_video_stream("highway.mp4", skip=3):
    # 每 4 帧处理一帧（跳 3 帧）
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    if idx % 100 == 0:
        print(f"已处理 {idx} 帧...")
```

### 3.3 批量生成器（模型推理中的常用模式）

```python
def batch_generator(
    data_loader,           # 数据加载器
    batch_size: int = 32   # 批大小
):
    """
    将数据分批产出——适配模型推理的 batch 输入
    """
    batch = []
    for item in data_loader:
        batch.append(item)
        if len(batch) == batch_size:
            yield batch
            batch = []
    # 剩余不足一个 batch 的数据
    if batch:
        yield batch

# 使用
dataset = range(100)  # 100 张图片
for batch in batch_generator(dataset, batch_size=16):
    print(f"处理 batch，大小: {len(batch)}")
    # model(batch)  # 批量推理
```

## 4. `itertools` 实用工具

```python
from itertools import islice, cycle, count

# islice——切片生成器（不用转成 list）
first_10 = islice(frame_generator("video.mp4"), 10)
for frame in first_10:
    process(frame)

# cycle——循环遍历（例如在固定几种颜色间轮换）
colors = cycle(["red", "green", "blue"])
for _ in range(5):
    print(next(colors))  # red, green, blue, red, green

# count——无限计数器（配合 zip 使用）
for frame_idx, frame in zip(count(), frame_generator("video.mp4")):
    if frame_idx >= 100:
        break
    process(frame)
```

## 面试常问

> **生成器和列表推导式的区别？**

| 对比 | 列表推导式 | 生成器表达式 |
|------|-----------|-------------|
| 语法 | `[x for x in ...]` | `(x for x in ...)` |
| 求值 | 立即求值（全部在内存） | 惰性求值（按需产出） |
| 内存 | O(n) | O(1) |
| 可迭代次数 | 任意次 | 一次 |
| 适用场景 | 数据量小、需多次访问 | 数据量大、只需遍历一次 |

## 必须掌握的要点

1. **`yield` 关键字**：能写出逐帧读取视频的生成器（面试手撕高频题）
2. **生成器 vs 列表**：数据量大时必须用生成器，避免内存溢出
3. **`itertools.islice`**：对生成器做切片取前 N 个
4. **批处理模式**：`batch_generator` 是模型推理的标准写法
