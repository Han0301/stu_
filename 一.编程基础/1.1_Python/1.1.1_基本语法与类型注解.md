## 2. 类型注解 ⭐⭐

### 2.1 为什么类型注解在视觉项目中重要？

```python
from typing import List, Tuple, Optional, Dict, NamedTuple

# ❌ 不写类型——半年后自己都看不懂
def process(boxes, scores, threshold):
    ...

# ✅ 写类型——一目了然
def process(
    boxes: List[Tuple[int, int, int, int]],  # 检测框列表
    scores: List[float],                      # 对应的置信度
    threshold: float = 0.5                    # 筛选阈值
) -> List[Tuple[int, int, int, int]]:         # 返回筛选后的框
    return [box for box, s in zip(boxes, scores) if s > threshold]
```

### 2.2 视觉项目中的典型类型定义

```python
from typing import NamedTuple, Optional

# 定义检测框数据结构——比用裸 tuple 清晰得多
class BBox(NamedTuple):
    """边界框 (xyxy 格式)"""
    x1: int
    y1: int
    x2: int
    y2: int

class Detection(NamedTuple):
    """单个检测结果"""
    bbox: BBox
    score: float
    label: str

class Track(NamedTuple):
    """跟踪目标"""
    track_id: int
    detections: List[Detection]
    is_active: bool = True

# 使用示例
det = Detection(bbox=BBox(100, 200, 300, 400), score=0.95, label="car")
print(f"检测到 {det.label}，置信度 {det.score}")
```

### 2.3 常见类型注解速查

| 类型 | 写法 | 视觉用途 |
|------|------|----------|
| 列表 | `List[float]` | 置信度列表 |
| 元组 | `Tuple[int, int]` | 像素坐标 (u, v) |
| 可选 | `Optional[float]` = `Union[float, None]` | 可能缺失的关键点 |
| 字典 | `Dict[str, Detection]` | 按 ID 索引的跟踪目标 |
| 联合 | `Union[int, float]` | 支持整数或浮点的参数 |
| 任意 | `Any` | 模型输出的原始 tensor |

```python
from typing import Optional

# 关键点检测——可能某些点被遮挡
def get_keypoint(
    keypoints: List[Tuple[int, int]],
    idx: int
) -> Optional[Tuple[int, int]]:
    """获取第 idx 个关键点，若被遮挡返回 None"""
    if idx >= len(keypoints):
        return None
    return keypoints[idx]
```

## 3. 类与面向对象

```python
class KalmanFilter:
    """一维卡尔曼滤波器——目标跟踪的基础"""
    
    def __init__(self, x0: float, P0: float, Q: float, R: float):
        self.x = x0      # 状态估计
        self.P = P0      # 协方差
        self.Q = Q       # 过程噪声
        self.R = R       # 观测噪声
    
    def predict(self) -> float:
        self.x = self.x          # 状态预测（恒定速度模型简化）
        self.P = self.P + self.Q
        return self.x
    
    def update(self, z: float) -> float:
        K = self.P / (self.P + self.R)    # 卡尔曼增益
        self.x = self.x + K * (z - self.x)
        self.P = (1 - K) * self.P
        return self.x

# 使用
kf = KalmanFilter(x0=0.0, P0=1.0, Q=0.1, R=0.5)
for measurement in [1.2, 1.5, 1.3, 1.7]:
    kf.predict()
    filtered = kf.update(measurement)
    print(f"观测: {measurement:.2f}, 滤波后: {filtered:.2f}")
```

## 必须掌握的要点

1. **列表推导式**：`[x for x in ... if cond]`——后处理筛选的标配写法
2. **NamedTuple 定义数据结构**：检测框、跟踪目标等都应该用 NamedTuple
3. **类型注解**：函数参数和返回值必须标注类型，大型项目必备
4. **类和 `__init__`**：滤波器、数据加载器等都会用到
