# 1.3.7 图与 DFS/BFS 遍历 ⭐⭐

> **机器人视觉定位**：**DFS 遍历 SLAM 共视图**——当相机在不同位置看到同一场景时，它们之间有"共视"关系，形成一个图。DFS 用于拓扑排序，BFS 用于求最短路径。图遍历算法是 SLAM 后端优化的基础。

---

## 1. 图的本质

**图 = 节点（node）+ 边（edge）**。视觉中，节点是关键帧，边表示两帧有共同观测点。

```cpp
#include <vector>

// 邻接表表示法——最常用的图存储方式
// graph[i] = 所有与节点 i 相连的节点
using Graph = std::vector<std::vector<int>>;

// 创建一个 5 个节点的图
Graph graph(5);
graph[0] = {1, 2};      // 节点 0 与节点 1、2 相连
graph[1] = {0, 3};      // 节点 1 与节点 0、3 相连
graph[2] = {0, 4};
graph[3] = {1, 4};
graph[4] = {2, 3};
```

---

## 2. DFS vs BFS —— 本质区别

| 对比 | DFS（深度优先） | BFS（广度优先） |
|------|:--------------:|:--------------:|
| **本质** | 一头扎到底，撞墙再回头 | 一圈一圈往外扩 |
| **数据结构** | 栈（stack） | 队列（queue） |
| **空间** | O(树高) | O(树宽) |
| **适用场景** | 拓扑排序、共视图遍历 | 最短路径、连通域 |

```cpp
#include <iostream>
#include <vector>
#include <stack>
#include <queue>
#include <unordered_set>

// ===== DFS：用栈（后进先出） =====
void dfs_stack(const Graph& graph, int start) {
    std::stack<int> st;
    std::unordered_set<int> visited;
    
    st.push(start);
    
    while (!st.empty()) {
        int node = st.top();  // 取栈顶——最后加入的节点
        st.pop();
        
        if (visited.find(node) != visited.end())
            continue;
        
        visited.insert(node);
        std::cout << "DFS 访问: " << node << std::endl;
        
        // 将邻居入栈（逆序，保证按原始顺序访问）
        const auto& neighbors = graph[node];
        for (auto it = neighbors.rbegin(); it != neighbors.rend(); ++it) {
            if (visited.find(*it) == visited.end())
                st.push(*it);
        }
    }
}

// ===== BFS：用队列（先进先出） =====
void bfs_queue(const Graph& graph, int start) {
    std::queue<int> q;
    std::unordered_set<int> visited;
    
    q.push(start);
    visited.insert(start);
    
    while (!q.empty()) {
        int node = q.front();  // 取队首——最先加入的节点
        q.pop();
        
        std::cout << "BFS 访问: " << node << std::endl;
        
        for (int neighbor : graph[node]) {
            if (visited.find(neighbor) == visited.end()) {
                visited.insert(neighbor);
                q.push(neighbor);
            }
        }
    }
}
```

> **DFS 和 BFS 的代码几乎一模一样，唯一的区别就在：**
> - DFS 从**栈末尾**取元素（`stack.top()` / `stack.pop()`）
> - BFS 从**队列开头**取元素（`queue.front()` / `queue.pop()`）
> 
> 这个微小的差别决定了完全不同的遍历顺序。

## 3. 视觉应用：SLAM 共视图遍历

SLAM 中的共视图是一个无向图：**节点是关键帧，边表示两帧共同观测到至少 N 个 3D 点。**

```cpp
#include <vector>
#include <stack>
#include <unordered_set>

struct KeyFrame {
    int id;
    // 其他信息：位姿、特征点等
};

// SLAM 共视图——邻接表
class CovisibilityGraph {
private:
    std::vector<std::vector<int>> adj_;  // 邻接表
    std::vector<KeyFrame> keyframes_;
    
public:
    // DFS 遍历共视图，收集与 start_id 连通的所有关键帧
    std::vector<int> get_connected_component(int start_id) {
        std::vector<int> component;
        std::stack<int> st;
        std::unordered_set<int> visited;
        
        st.push(start_id);
        
        while (!st.empty()) {
            int id = st.top();
            st.pop();
            
            if (visited.find(id) != visited.end())
                continue;
            
            visited.insert(id);
            component.push_back(id);
            
            // 只遍历与当前帧有"强共视"关系的帧
            for (int neighbor : adj_[id]) {
                if (visited.find(neighbor) == visited.end())
                    st.push(neighbor);
            }
        }
        
        return component;
    }
    
    // BFS 求两帧之间的最短路径（共视跳数）
    std::vector<int> shortest_path(int from, int to) {
        std::queue<int> q;
        std::vector<int> prev(keyframes_.size(), -1);
        std::vector<bool> visited(keyframes_.size(), false);
        
        q.push(from);
        visited[from] = true;
        
        while (!q.empty()) {
            int cur = q.front();
            q.pop();
            
            if (cur == to) break;
            
            for (int neighbor : adj_[cur]) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    prev[neighbor] = cur;
                    q.push(neighbor);
                }
            }
        }
        
        // 回溯路径
        std::vector<int> path;
        for (int v = to; v != -1; v = prev[v])
            path.push_back(v);
        std::reverse(path.begin(), path.end());
        
        if (path.front() == from)
            return path;
        return {};  // 不存在路径
    }
};
```

## 4. 拓扑排序

SLAM 后端优化中需要按依赖关系排列优化顺序——这就是拓扑排序。

```cpp
#include <vector>
#include <stack>

// 拓扑排序（Kahn 算法）
// 返回拓扑序，如果图有环返回空
std::vector<int> topological_sort(const Graph& graph) {
    int n = graph.size();
    std::vector<int> in_degree(n, 0);  // 入度表
    
    // 计算每个节点的入度
    for (int u = 0; u < n; u++) {
        for (int v : graph[u]) {
            in_degree[v]++;
        }
    }
    
    // 将所有入度为 0 的节点入队
    std::queue<int> q;
    for (int i = 0; i < n; i++) {
        if (in_degree[i] == 0)
            q.push(i);
    }
    
    std::vector<int> result;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        result.push_back(u);
        
        for (int v : graph[u]) {
            if (--in_degree[v] == 0)
                q.push(v);
        }
    }
    
    // 如果结果长度不等于节点数，说明图有环
    return result.size() == n ? result : std::vector<int>();
}
```

## 面试常考

> **Q1: DFS 和 BFS 的代码结构对比？**

```
两段代码几乎一模一样，唯一区别：
  DFS: stack（后进先出），从栈顶 pop
  BFS: queue（先进先出），从队首 pop
这个差别决定了 DFS 沿着一条路走到底，BFS 逐层扩散。
```

> **Q2: 有向图和无向图的区别？**

```
无向图：边是双向的，A-B 意味着 A→B 且 B→A
有向图：边是单向的，A→B 不意味着 B→A
SLAM 共视图是无向图；拓扑排序是在有向无环图上做的。
```

**5. 原理追问** ⭐
图的邻接表和邻接矩阵有什么区别？在什么场景下选择用邻接表？

**参考答案**
1. DFS 从栈顶取（后进先出），BFS 从队首取（先进先出）
2. 略
3. DFS 适合找"与当前帧强相关的所有帧"，BFS 适合找"最短共视路径"
4. Kahn 算法：不断删除入度为 0 的节点，最终顺序就是拓扑序
5. 邻接表省空间（O(V+E)），适合稀疏图；邻接矩阵查找快（O(1)），适合稠密图
