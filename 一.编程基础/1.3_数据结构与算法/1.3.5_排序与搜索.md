# 1.3.5 排序与搜索 ⭐⭐

> **机器人视觉定位**：排序是按置信度筛选检测框的基本操作。二分搜索用于参数调优——比如用二分法找到使 mAP 最高的 NMS 阈值。在视觉算法中，"先排序再取 Top-K"是最常见的后处理模式。

---

## 1. 排序的本质

**排序 = 按照某种规则将元素重新排列。** Python 的 `sort` 用 Timsort（归并+插入），C++ 的 `sort` 用 IntroSort（快排+堆排+插入），都是 O(n log n)。

### 1.1 C++ sort

```cpp
#include <algorithm>
#include <vector>

struct Detection {
    float x1, y1, x2, y2, score;
    int label;
};

// 按置信度降序排列
std::sort(detections.begin(), detections.end(),
    [](const Detection& a, const Detection& b) {
        return a.score > b.score;  // > 表示降序
    });
```

**关键语法拆解：**
- `sort(begin, end, cmp)` — 对 [begin, end) 范围内的元素排序
- 第三个参数 `cmp` 是**比较器**，可以是函数指针、函数对象或 lambda
- `return a.score > b.score` —— 如果 a 的分数比 b 大，a 排在 b 前面（降序）
- 默认 `return a < b` 是升序（从小到大）

### 1.2 stable_sort

如果需要保留等值元素的原始相对顺序（例如先按分数排，相同分数的按时间戳排），用 `stable_sort`：

```cpp
std::stable_sort(detections.begin(), detections.end(), ...);
// stable_sort 保证相等元素的顺序不变，但比 sort 略慢
```

## 2. 二分搜索 ⭐⭐

### 2.1 本质

**二分搜索 = 每次砍掉一半不可能的区域。** 前提是数据已经排好序。

```cpp
#include <algorithm>

// 标准库二分搜索
std::vector<int> data = {1, 3, 5, 7, 9, 11, 13};

// binary_search：返回 true/false
bool found = std::binary_search(data.begin(), data.end(), 7);  // true

// lower_bound：第一个 >= target 的位置
auto it = std::lower_bound(data.begin(), data.end(), 6);
// *it = 7（第一个 >= 6 的元素）

// upper_bound：第一个 > target 的位置
auto it2 = std::upper_bound(data.begin(), data.end(), 7);
// *it2 = 9（第一个 > 7 的元素）
```

### 2.2 视觉应用：二分搜索找最优 NMS 阈值

```cpp
#include <algorithm>
#include <cmath>

float find_optimal_nms_threshold(
    const std::vector<Detection>& dets,
    const std::vector<GroundTruth>& gts,
    float target_map = 0.5) {
    
    // 二分搜索：在 [0.1, 0.9] 范围内找使 mAP 最接近 target 的阈值
    float lo = 0.1f, hi = 0.9f;
    float best_thresh = 0.5f;
    float best_diff = 1e9f;
    
    while (hi - lo > 0.01f) {
        float mid = (lo + hi) / 2.0f;
        
        // 用当前阈值计算 mAP
        float current_map = evaluate_map(dets, gts, mid);
        float diff = std::abs(current_map - target_map);
        
        if (diff < best_diff) {
            best_diff = diff;
            best_thresh = mid;
        }
        
        // 根据 mAP 与目标的差距调整搜索范围
        if (current_map > target_map) {
            lo = mid;  // 阈值越大 → 保留框越少 → mAP 越低
        } else {
            hi = mid;
        }
    }
    
    return best_thresh;
}
```

## 3. 排序与搜索的时空权衡

```
排序 O(n log n) + 二分搜索 O(log n)
    vs
直接在无序数组中遍历 O(n)

当需要多次搜索时，排序是值得的：
  1 次搜索：遍历更快（不需要排序开销）
  10 次搜索：排序 + 二分 ≈ 遍历（差不多）
  100 次搜索：排序 + 二分 远快于遍历（10 倍以上）
```

## 面试常考

> **Q1: 快排为什么是 O(n log n)？**

```
每次 partition 将数组分成两半（log n 层），
每层遍历所有元素（n 个），
所以总复杂度 = n × log n = O(n log n)。
最坏情况（已排序）：每层只分出一个元素，退化为 O(n²)。
所以 C++ sort 在检测到递归过深时会自动切换到堆排序。
```

> **Q2: 二分搜索的先决条件是什么？数组必须有序。如果数据频繁插入怎么办？**

```
可以用平衡二叉搜索树（如 std::set、std::map），
插入和搜索都是 O(log n)，不需要重新排序。
```
