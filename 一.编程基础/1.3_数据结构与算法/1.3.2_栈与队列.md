# 1.3.2 栈与队列 ⭐⭐

> **机器人视觉定位**：栈和队列是视觉 Pipeline 中"按顺序处理数据"的基本工具。队列做帧缓冲（先进先出），栈做 DFS 遍历（后进先出），优先队列加速 NMS 排序。

---

## 1. 栈（Stack）——后进先出

### 1.1 本质

栈就像一摞盘子——你只能从最上面取，也只能往最上面放。

```
push(1) → [1]
push(2) → [1, 2]
pop()   → [1]     取出 2（最后进来的最先出去）
```

```cpp
#include <stack>

std::stack<int> s;
s.push(1);          // 压栈
s.push(2);
int top = s.top();   // 取栈顶 → 2（不删除）
s.pop();            // 弹出栈顶 → 删除 2
```

### 1.2 视觉应用：DFS 遍历 SLAM 共视图

SLAM 共视图是一个图，每个节点是关键帧，边表示两帧有共同观测点。DFS 用于拓扑排序。

```cpp
#include <stack>
#include <vector>
#include <unordered_set>

void dfs_slam(const std::vector<std::vector<int>>& graph, int start) {
    // graph[node] = 与该节点相连的所有节点
    std::stack<int> st;
    std::unordered_set<int> visited;
    
    st.push(start);
    
    while (!st.empty()) {
        int node = st.top();  // 取栈顶（当前要访问的节点）
        st.pop();
        
        if (visited.find(node) != visited.end())
            continue;
        
        visited.insert(node);
        // 处理当前关键帧...
        
        for (int neighbor : graph[node]) {
            if (visited.find(neighbor) == visited.end())
                st.push(neighbor);
        }
    }
}
```

> **栈的关键规律**：后进先出决定了 DFS 会"一头扎到底"——先一直往深处走，走不通才回头。这正是"深度优先"名字的由来。

## 2. 队列（Queue）——先进先出

### 2.1 本质

队列就像排队买票——先来的人先买到，后来的人排后面。

```
push(1) → [1]
push(2) → [1, 2]
pop()   → [2]     取出 1（最先来的最先出去）
```

```cpp
#include <queue>

std::queue<int> q;
q.push(1);
q.push(2);
int front = q.front();  // 取队首 → 1（不删除）
q.pop();                // 弹出队首 → 删除 1
```

### 2.2 视觉应用：BFS 图像连通域分析

```cpp
#include <queue>
#include <vector>

struct Point { int x, y; };

std::vector<Point> bfs_connected_component(
    const std::vector<std::vector<int>>& image, 
    Point start, int width, int height) {
    
    std::queue<Point> q;
    std::vector<Point> component;
    q.push(start);
    
    int dx[] = {1, -1, 0, 0};
    int dy[] = {0, 0, 1, -1};
    
    while (!q.empty()) {
        Point cur = q.front();  // 取队首（最早来的点）
        q.pop();
        component.push_back(cur);
        
        for (int i = 0; i < 4; i++) {
            int nx = cur.x + dx[i];
            int ny = cur.y + dy[i];
            if (nx >= 0 && nx < width && ny >= 0 && ny < height 
                && image[ny][nx] == 255) {
                q.push({nx, ny});
                image[ny][nx] = 0;  // 标记已访问
            }
        }
    }
    return component;
}
```

> **队列的关键规律**：先进先出决定了 BFS 会"一圈一圈往外扩"——先处理离起点最近的，再处理稍远的，直到全部处理完。这就是"广度优先"名字的由来。

## 3. 优先队列（Priority Queue）——堆

### 3.1 本质

优先队列不再是"先来后到"，而是**谁优先级高谁先出**。底层实现是堆（heap）。

```cpp
#include <queue>
#include <vector>

// 默认最大堆（最大的优先）
std::priority_queue<int> pq;
pq.push(3);
pq.push(1);
pq.push(5);
std::cout << pq.top();  // 5（最大的最先出来）
pq.pop();               // 删除 5
std::cout << pq.top();  // 3

// 最小堆（最小的优先）——用 greater
std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;
```

### 3.2 视觉应用：NMS 候选框排序

```cpp
#include <queue>
#include <vector>

struct Detection {
    float x1, y1, x2, y2, score;
    int label;
};

// 按置信度排序的比较器
struct CompareScore {
    bool operator()(const Detection& a, const Detection& b) {
        return a.score < b.score;  // 分数高的优先（最大堆）
    }
};

std::vector<Detection> nms_with_heap(
    std::vector<Detection>& dets, float iou_thresh) {
    
    // 最大堆：置信度最高的候选框在堆顶
    std::priority_queue<Detection, std::vector<Detection>, CompareScore> pq;
    for (auto& det : dets) pq.push(det);
    
    std::vector<Detection> keep;
    while (!pq.empty()) {
        auto best = pq.top();  // 取当前置信度最高的框
        pq.pop();
        
        bool should_keep = true;
        for (const auto& kept : keep) {
            if (compute_iou(best, kept) > iou_thresh) {
                should_keep = false;
                break;
            }
        }
        if (should_keep) keep.push_back(best);
    }
    return keep;
}
```

## 栈 vs 队列 vs 优先队列——本质对比

```
栈：      后进先出  → DFS 遍历
队列：    先进先出  → BFS 遍历
优先队列：按优先级  → NMS 排序、Top-K

三者的代码结构几乎一样：
  栈：   push/pop 从同一端操作
  队列： push 一端 / pop 另一端
  优先队列：push 自动排序 / pop 取最大/最小
```

## 面试常考

> **Q1: 栈和队列的底层实现方式？**

```
栈和队列都是"适配器容器"——底层可以用 vector/deque/list 实现。
默认底层是 deque，因为它支持两端高效操作。
所以 stack 和 queue 不直接存储数据，而是调用底层容器的接口。
```

> **Q2: 为什么 NMS 用优先队列比全排序快？**

```
全排序 O(N log N)：给所有框排好名次，不管需不需要
优先队列 O(N log K)：只维护当前最优的几个候选
直观理解：挑选前 5 个最好的，只需维护一个大小为 5 的名单
```

**2. 代码实践** ⭐⭐⭐（C++ 实现）
用 C++ 实现一个环形队列（循环缓冲区）类 `CircularBuffer<T>`，用于存储最近 N 帧的检测结果。要求提供 `push`、`get_latest`、`size` 三个方法。

**3. 视觉关联** ⭐⭐
在实时视频处理中，为什么要用队列做帧缓冲？如果不用队列而用数组手动管理 FIFO，会有什么问题？

**4. 原理追问** ⭐⭐
优先队列的底层是堆，堆的插入和删除时间复杂度分别是 O(log n)。如果 NMS 有 1000 个候选框，用优先队列比全排序快多少倍？

**参考答案**
1. 栈：后进先出；队列：先进先出；优先队列：按优先级
2. 略
3. 队列自动管理"先进先出"，只要不断 `pop` 最老的帧、`push` 最新的帧。数组需要手动维护头尾指针
4. 全排序 O(N log N) ≈ 1000×10 = 10000；优先队列 O(N log K) ≈ 1000×3 = 3000（K≈8），快 3 倍+
