# 1.3.4 二叉树与堆 ⭐⭐

> **机器人视觉定位**：**堆（优先队列）** 是 NMS（非极大值抑制）的核心数据结构——每次从一堆候选框中取置信度最高的那个，用最大堆比全排序快一个数量级。**二叉树**的变种 KD-Tree 用于点云最近邻搜索，是 ICP 配准的基础。

---

## 1. 二叉树的本质

二叉树就是一种**每个节点最多两个子节点**的树结构。

```cpp
struct TreeNode {
    int val;
    TreeNode* left;   // 左子节点
    TreeNode* right;  // 右子节点
};
```

但机器人视觉中直接用二叉树的时候很少。真正常用的是它的两个特殊变种：**堆** 和 **KD-Tree**。

---

## 2. 堆（Heap）——优先队列的底层 ⭐⭐

### 2.1 本质

**堆 = 一种特殊的完全二叉树，父节点的值永远比子节点大（最大堆）或小（最小堆）。**

```
最大堆（最大的在堆顶）：
        100
       /   \
      50    80
     /  \  /  \
    30  20 40  10

最小堆（最小的在堆顶）：
        10
       /  \
      20   30
     /  \  / \
    40  50 60  70
```

```cpp
#include <queue>
#include <vector>

// C++ 的优先队列默认是最大堆
std::priority_queue<int> max_heap;
max_heap.push(3);
max_heap.push(1);
max_heap.push(5);
std::cout << max_heap.top();  // 5（最大值在堆顶）

// 最小堆
std::priority_queue<int, std::vector<int>, std::greater<int>> min_heap;
min_heap.push(3);
min_heap.push(1);
min_heap.push(5);
std::cout << min_heap.top();  // 1（最小值在堆顶）
```

### 2.2 视觉应用：NMS 中的 Top-K

```cpp
#include <queue>
#include <vector>

struct Detection {
    float x1, y1, x2, y2;
    float score;
};

// 从 N 个候选框中取置信度最高的 K 个
// 用最小堆实现：维护一个大小为 K 的堆，最后剩下的就是 Top-K
std::vector<Detection> top_k_detections(
    const std::vector<Detection>& dets, int k) {
    
    if (k <= 0) return {};
    
    // 最小堆——堆顶始终是最小的（最差的候选）
    auto cmp = [](const Detection& a, const Detection& b) {
        return a.score > b.score;  // 注意：> 是最小堆
    };
    std::priority_queue<Detection, std::vector<Detection>, decltype(cmp)> min_heap(cmp);
    
    for (const auto& det : dets) {
        min_heap.push(det);
        if ((int)min_heap.size() > k) {
            min_heap.pop();  // 弹出最差的（堆顶）
        }
    }
    
    // 堆里剩下的就是 Top-K
    std::vector<Detection> result;
    while (!min_heap.empty()) {
        result.push_back(min_heap.top());
        min_heap.pop();
    }
    return result;
}
```

> **为什么用最小堆找 Top-K？**
>
> 我们要的是"前 K 大的"，所以维护一个大小为 K 的**最小堆**。堆顶是 K 个中最小的那个——每来一个新元素，如果比堆顶大，就踢掉堆顶、加入新元素。最后堆里剩下的就是最大的 K 个。
>
> 时间复杂度：O(N log K)，比全排序 O(N log N) 快。

## 3. KD-Tree——点云最近邻搜索 ⭐

### 3.1 本质

KD-Tree 是一种**多维空间的二叉搜索树**。它按维度交替分割空间，将点云组织成树结构，使最近邻搜索从 O(n) 降到 O(log n)。

```
二维 KD-Tree 示例（交替按 x/y 轴分割）：
         (x=5)
        /     \
    (y=3)    (y=7)
    /   \     /   \
 (2,1) (4,5)(6,4)(8,9)
```

```cpp
// 在 PCL 中使用 KD-Tree（实际项目中不用自己实现）
#include <pcl/kdtree/kdtree_flann.h>

pcl::KdTreeFLANN<pcl::PointXYZ> kdtree;
kdtree.setInputCloud(cloud);

// 查找最近邻 — O(log n)
pcl::PointXYZ search_point(1.0, 2.0, 3.0);
std::vector<int> indices(1);
std::vector<float> distances(1);

kdtree.nearestKSearch(search_point, 1, indices, distances);
// indices[0] = 最近点的索引
// distances[0] = 距离平方
```

## 面试常考

> **Q1: 堆的插入和删除复杂度为什么是 O(log n)？**

```
堆用数组存储，父子节点的下标关系：
  parent = (i-1)/2
  left = 2*i + 1
  right = 2*i + 2

插入：放到末尾 → 向上比较交换（上浮）→ 最多 log n 层
删除堆顶：用末尾元素替换堆顶 → 向下比较交换（下沉）→ 最多 log n 层
```

> **Q2: KD-Tree 为什么适用于点云配准？**

```
ICP 配准中需要为源点云的每个点找目标点云中的最近邻。
暴力遍历 O(n²)，用 KD-Tree 可以降到 O(n log n)。
对于 10 万个点的点云，速度差约 5000 倍。
```

**3. 视觉关联** ⭐⭐
在 ICP 点云配准中，KD-Tree 解决了什么问题？如果不使用 KD-Tree，暴力搜索的时间复杂度是多少？

**4. 原理追问** ⭐
堆的"上浮"和"下沉"操作分别对应什么场景？分别发生在插入和删除中的哪一步？

**参考答案**
1. 最大堆堆顶最大，最小堆堆顶最小。用最小堆存 Top-K：堆顶是 K 个中最差的，新元素比堆顶好就替换。用最大堆的话需要把所有元素都塞进去
2. 略
3. 最近邻搜索从 O(n²) 降到 O(n log n)
4. 插入时新元素在末尾，上浮到正确位置；删除时堆顶被移除，尾部元素替换到堆顶，下沉到正确位置
