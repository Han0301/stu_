# 1.2.2 STL 容器与 CMake 工程构建

> **机器人视觉定位**：STL 容器是 C++ 视觉代码的"工具箱"—— `vector` 存检测框、`unordered_map` 做快速 ID 查找、`queue` 做帧缓冲。**CMake** 是所有 C++ 视觉工程的构建系统，不懂 CMake 意味着无法编译你的代码。

---

## 1. STL 容器 ⭐⭐

### 1.1 容器选型对比

| 容器 | 特点 | 查找 | 插入/删除 | 视觉用途 |
|------|------|:----:|:---------:|----------|
| `std::vector` | 连续内存，cache friendly | O(1) 随机访问 | 尾部 O(1)，中间 O(n) | 检测框列表、特征点集 |
| `std::list` | 双向链表 | O(n) | 已知位置 O(1) | Tracklet 轨迹管理 |
| `std::deque` | 双端队列 | O(1) | 两端 O(1) | 滑动窗口帧缓冲 |
| `std::map` | 有序键值对（红黑树） | O(log n) | O(log n) | 按时间戳排序的传感器数据 |
| `std::unordered_map` | 哈希表 | O(1) 平均 | O(1) 平均 | 按 ID 查找跟踪目标 |
| `std::priority_queue` | 堆 | O(1) 取最大 | O(log n) | NMS 候选框排序 |

### 1.2 `std::vector`——最常用的容器

```cpp
#include <vector>
#include <algorithm>

struct Detection {
    float x1, y1, x2, y2;
    float score;
    int label;
};

// 存储检测结果
std::vector<Detection> detections;

// 添加
detections.push_back({100, 200, 300, 400, 0.95, 0});
detections.push_back({150, 250, 350, 450, 0.87, 1});

// 按置信度降序排序
std::sort(detections.begin(), detections.end(),
    [](const Detection& a, const Detection& b) {
        return a.score > b.score;
    });

// 取 Top-K
int k = 5;
if (detections.size() > k) {
    detections.resize(k);
}

// 遍历
for (const auto& det : detections) {
    std::cout << "label=" << det.label 
              << " score=" << det.score << std::endl;
}
```

### 1.3 `std::unordered_map`——快速 ID 查找

```cpp
#include <unordered_map>

// 跟踪目标池——按 ID 快速查找
std::unordered_map<int, Detection> tracked_objects;

// 添加/更新
tracked_objects[1] = {100, 200, 300, 400, 0.95, 0};
tracked_objects[2] = {150, 250, 350, 450, 0.87, 1};

// 查找
int target_id = 1;
auto it = tracked_objects.find(target_id);
if (it != tracked_objects.end()) {
    const auto& det = it->second;
    // 找到了目标 ID=1
} else {
    // 目标丢失
}

// 删除
tracked_objects.erase(target_id);
```

### 1.4 `std::deque`——滑动窗口

```cpp
#include <deque>

// 滑动窗口存储最近 N 帧的检测结果
std::deque<std::vector<Detection>> frame_history;
const int WINDOW_SIZE = 30;

void add_frame(const std::vector<Detection>& dets) {
    frame_history.push_back(dets);
    if (frame_history.size() > WINDOW_SIZE) {
        frame_history.pop_front();  // 移除最老帧
    }
}
```

## 2. CMake 工程构建 ⭐⭐⭐

### 2.1 最小 CMakeLists.txt

```cmake
cmake_minimum_required(VERSION 3.16)
project(PerceptionNode)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 查找依赖
find_package(OpenCV REQUIRED COMPONENTS core imgproc dnn highgui)
find_package(TensorRT REQUIRED)

# 添加可执行文件
add_executable(detection_node src/main.cpp src/detector.cpp)

# 链接库
target_link_libraries(detection_node
    ${OpenCV_LIBS}
    ${TensorRT_LIBRARIES}
)

# 包含头文件路径
target_include_directories(detection_node PRIVATE
    ${OpenCV_INCLUDE_DIRS}
    ${TensorRT_INCLUDE_DIRS}
    src/
)
```

### 2.2 常用 CMake 命令速查

```cmake
# ==== 查找库 ====
find_package(OpenCV REQUIRED)                     # 系统安装的库
find_package(TensorRT REQUIRED PATHS /usr/local/) # 指定路径

# ==== 目标类型 ====
add_executable(my_node main.cpp)                   # 可执行文件
add_library(my_lib SHARED lib.cpp)                 # 动态库
add_library(my_lib STATIC lib.cpp)                 # 静态库

# ==== 头文件路径 ====
target_include_directories(my_node PRIVATE include/)

# ==== 链接库 ====
target_link_libraries(my_node PRIVATE ${OpenCV_LIBS})

# ==== 编译选项 ====
target_compile_options(my_node PRIVATE -Wall -O3)
target_compile_definitions(my_node PRIVATE USE_CUDA)

# ==== 安装 ====
install(TARGETS my_node DESTINATION bin/)
```

### 2.3 多模块工程结构

```cmake
# 实际机器人感知项目的 CMake 结构
project(RobotPerception)

# 子模块
add_subdirectory(src/detection)    # 检测模块
add_subdirectory(src/tracking)     # 跟踪模块
add_subdirectory(src/fusion)       # 融合模块
add_subdirectory(src/common)       # 公共工具

# 主节点
add_executable(perception_node src/main.cpp)
target_link_libraries(perception_node PRIVATE
    detection_lib
    tracking_lib
    fusion_lib
    common_lib
)
```

### 2.4 常见编译错误及解决

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `fatal error: opencv2/opencv.hpp: No such file` | OpenCV 未找到 | 检查 `find_package(OpenCV)` 路径 |
| `undefined reference to 'cv::imread'` | 未链接 OpenCV 库 | 添加 `target_link_libraries` |
| `Could not find cmake module` | 依赖找不到 | 安装依赖或用 `PATHS` 指定路径 |
| `CMAKE_CXX_STANDARD` 不匹配 | C++ 标准版本问题 | 设为 17 或 20 |

## 面试常问

> **Q1: `std::vector` 的 `push_back` 和 `emplace_back` 区别？**

```
push_back：传入已构造的对象，会触发拷贝/移动构造
emplace_back：传入构造参数，在容器内就地构造，避免一次拷贝
推荐：构造新元素时用 emplace_back
```

> **Q2: `std::map` 和 `std::unordered_map` 怎么选？**

```
需要有序遍历 → map（红黑树，O(log n)）
只需要快速查找 → unordered_map（哈希表，O(1) 平均）
数据量小（< 100）→ 两者差别不大
```

## 必须掌握的要点

1. **`std::vector`**：最常用的容器，掌握 `push_back`/`emplace_back`/`sort`/`resize`
2. **`std::unordered_map`**：哈希表实现，用于快速 ID 查找
3. **CMake 三件套**：`find_package` + `add_executable` + `target_link_libraries`
4. **编译流程**：`mkdir build && cd build && cmake .. && make`
