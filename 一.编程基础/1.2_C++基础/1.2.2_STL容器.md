# 1.2.2 STL 容器与 CMake 工程构建

> **机器人视觉定位**：STL 容器是 C++ 视觉代码的"工具箱"—— `vector` 存检测框、`unordered_map` 做快速 ID 查找、`deque` 做滑动窗口帧缓冲。掌握 STL 容器是写 C++ 视觉代码的前提。

---

## 1. STL 容器 ⭐⭐

### 1.1 容器选型对比

| 容器 | 特点 | 查找 | 插入/删除 | 视觉用途 |
|------|------|:----:|:---------:|----------|
| `std::vector` | 连续内存，cache friendly | O(1) 随机访问 | 尾部 O(1)，中间 O(n) | 检测框列表、特征点集 |
| `std::list` | 双向链表 | O(n) | 已知位置 O(1) | Tracklet 轨迹管理 |
| `std::deque` | 双端队列 | O(1) | 两端 O(1) | 滑动窗口帧缓冲 |
| `std::map` | 有序键值对（红黑树） | O(log n) | O(log n) | 按时间戳排序的传感器数据 |
| `std::unordered_map` | 哈希表 | O(1) 平均 | O(1) 平均 | 按 ID 查找跟踪目标 |
| `std::priority_queue` | 堆 | O(1) 取最大 | O(log n) | NMS 候选框排序 |

### 1.2 `std::vector`——最常用的容器

```cpp
#include <vector>
#include <algorithm>

struct Detection {
    float x1, y1, x2, y2;
    float score;
    int label;
};

// 存储检测结果
std::vector<Detection> detections;

// 添加
detections.push_back({100, 200, 300, 400, 0.95, 0});
detections.push_back({150, 250, 350, 450, 0.87, 1});

// 按置信度降序排序
std::sort(detections.begin(), detections.end(),
    [](const Detection& a, const Detection& b) {
        return a.score > b.score;
    });

// 取 Top-K
int k = 5;
if (detections.size() > k) {
    detections.resize(k);
}

// 遍历
for (const auto& det : detections) {
    std::cout << "label=" << det.label 
              << " score=" << det.score << std::endl;
}
```

### 1.3 `std::unordered_map`——快速 ID 查找

```cpp
#include <unordered_map>

// 跟踪目标池——按 ID 快速查找
std::unordered_map<int, Detection> tracked_objects;

// 添加/更新
tracked_objects[1] = {100, 200, 300, 400, 0.95, 0};
tracked_objects[2] = {150, 250, 350, 450, 0.87, 1};

// 查找
int target_id = 1;
auto it = tracked_objects.find(target_id);
if (it != tracked_objects.end()) {
    const auto& det = it->second;
    // 找到了目标 ID=1
} else {
    // 目标丢失
}

// 删除
tracked_objects.erase(target_id);
```

### 1.4 `std::deque`——滑动窗口

```cpp
#include <deque>

// 滑动窗口存储最近 N 帧的检测结果
std::deque<std::vector<Detection>> frame_history;
const int WINDOW_SIZE = 30;

void add_frame(const std::vector<Detection>& dets) {
    frame_history.push_back(dets);
    if (frame_history.size() > WINDOW_SIZE) {
        frame_history.pop_front();  // 移除最老帧
    }
}
```

## 面试常问

> **Q1: `std::vector` 的 `push_back` 和 `emplace_back` 区别？**

```
push_back：传入已构造的对象，会触发拷贝/移动构造
emplace_back：传入构造参数，在容器内就地构造，避免一次拷贝
推荐：构造新元素时用 emplace_back
```

> **Q2: `std::map` 和 `std::unordered_map` 怎么选？**

```
需要有序遍历 → map（红黑树，O(log n)）
只需要快速查找 → unordered_map（哈希表，O(1) 平均）
数据量小（< 100）→ 两者差别不大
```
