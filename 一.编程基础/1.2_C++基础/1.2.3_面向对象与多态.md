# 1.2.3 面向对象与多态 ⭐⭐

> **机器人视觉定位**：面向对象是设计**可扩展感知模块架构**的基础。通过定义纯虚接口，可以轻松替换检测器（YOLO v5 → v8 → v9 无缝切换）。ROS 节点、TensorRT 引擎、相机驱动都围绕类封装展开。

---

## 1. 面向对象的本质

**面向对象 = 把"数据"和"操作数据的函数"打包在一起。**

```
C 语言： struct Point { float x, y; };      // 数据和函数分离
                  void move(Point* p, float dx, float dy);

C++ 类： class Point {                        // 数据和函数在一起
             float x, y;
             void move(float dx, float dy) { x += dx; y += dy; }
         };
```

## 2. 类与封装

### 2.1 基本类定义

```cpp
#include <string>
#include <vector>

class Detection {
private:
    // 私有成员——外部不能直接访问，通过接口操作
    float x1_, y1_, x2_, y2_;
    float score_;
    int label_;
    std::string class_name_;
    
public:
    // 构造函数——创建对象时自动调用
    Detection(float x1, float y1, float x2, float y2, 
              float score, int label, const std::string& name)
        : x1_(x1), y1_(y1), x2_(x2), y2_(y2)   // 初始化列表
        , score_(score), label_(label), class_name_(name) {}
    
    // 访问器（getter）——只读访问私有成员
    float score() const { return score_; }
    int label() const { return label_; }
    std::string class_name() const { return class_name_; }
    
    // 计算 IoU（与其他检测框的交并比）
    float iou(const Detection& other) const {
        float ix = std::max(x1_, other.x1_);
        float iy = std::max(y1_, other.y1_);
        float ax = std::min(x2_, other.x2_);
        float ay = std::min(y2_, other.y2_);
        
        float inter = std::max(0.0f, ax - ix) * std::max(0.0f, ay - iy);
        float area1 = (x2_ - x1_) * (y2_ - y1_);
        float area2 = (other.x2_ - other.x1_) * (other.y2_ - other.y1_);
        
        return inter / (area1 + area2 - inter + 1e-6f);
    }
};

// 使用
Detection det(100, 200, 300, 400, 0.95, 0, "car");
std::cout << det.class_name() << ": " << det.score();  // car: 0.95
```

**语法拆解：**
- `private:` — 私有成员，外部不能直接访问（用 `det.score_` 会编译错误）
- `public:` — 公有接口，外部可以通过这些方法操作对象
- `const` 成员函数（如 `score() const`）——承诺不修改对象状态，可安全调用
- 初始化列表 `: x1_(x1), y1_(y1)` — 在构造函数体执行前初始化成员，比在体内赋值更高效

## 3. 继承与多态 ⭐⭐

### 3.1 纯虚接口——算法插件化

```cpp
#include <memory>
#include <vector>

// ===== 抽象接口（纯虚类）：所有检测器必须实现 =====
class IDetector {
public:
    // 虚析构函数——确保通过基类指针删除时能调用到派生类的析构
    virtual ~IDetector() = default;
    
    // 纯虚函数 = 0：子类必须实现此方法
    virtual std::vector<Detection> detect(const cv::Mat& image) = 0;
    virtual std::string name() const = 0;
};

// ===== YOLO v8 实现 =====
class YOLOv8Detector : public IDetector {
public:
    explicit YOLOv8Detector(const std::string& model_path) {
        // 加载 YOLOv8 模型
        std::cout << "Loading YOLOv8 from: " << model_path << std::endl;
    }
    
    std::vector<Detection> detect(const cv::Mat& image) override {
        // YOLOv8 推理实现
        std::vector<Detection> results;
        // ... 推理逻辑 ...
        return results;
    }
    
    std::string name() const override {
        return "YOLOv8";
    }
};

// ===== Faster R-CNN 实现（另外一个实现） =====
class FasterRCNN : public IDetector {
public:
    explicit FasterRCNN(const std::string& model_path) {
        std::cout << "Loading Faster R-CNN from: " << model_path << std::endl;
    }
    
    std::vector<Detection> detect(const cv::Mat& image) override {
        // Faster R-CNN 推理实现
        return {};
    }
    
    std::string name() const override {
        return "Faster R-CNN";
    }
};
```

### 3.2 多态的使用

```cpp
// 统一接口，可无缝切换任意检测器
std::unique_ptr<IDetector> detector;

// 运行时决定使用哪个检测器
if (config.use_yolo) {
    detector = std::make_unique<YOLOv8Detector>("yolov8.pt");
} else {
    detector = std::make_unique<FasterRCNN>("faster_rcnn.pth");
}

// 不管用哪种检测器，调用方式完全一样
cv::Mat frame = cv::imread("test.jpg");
auto detections = detector->detect(frame);
std::cout << "Using: " << detector->name() << std::endl;

// 如果要换成 YOLOv9，只需要新增一个类，其余代码不动
```

## 4. 虚函数机制——面试高频

```cpp
class Base {
public:
    virtual void func() { std::cout << "Base\n"; }  // 虚函数：可被子类重写
    virtual ~Base() = default;                       // 虚析构：正确释放资源
};

class Derived : public Base {
public:
    void func() override { std::cout << "Derived\n"; }  // override：明确表示重写
};

Base* p = new Derived();
p->func();  // 输出 "Derived"（多态——调用实际类型的版本）
delete p;   // 正确调用 Derived 的析构（因为基类析构是 virtual）
```

**虚函数本质：**
```
每个有虚函数的类有一个虚函数表（vtable），
表里存着每个虚函数的实际地址。
调用虚函数时，通过 vtable 查找实际要调用的函数——这叫"动态绑定"。
没有 virtual 的普通函数，编译时就确定了——叫"静态绑定"。
```

## 面试常考

> **Q1: 虚函数和纯虚函数的区别？**

```
虚函数（virtual）：基类有默认实现，子类可选择重写
纯虚函数（virtual ... = 0）：基类无实现，子类必须重写
含纯虚函数的类叫"抽象类"，不能实例化，只能作为接口使用
```

> **Q2: 为什么析构函数通常声明为 virtual？**

```
通过基类指针删除派生类对象时，如果析构不是 virtual，
只会调用基类的析构，不会调用派生类的析构 → 资源泄漏。
举个例：IDetector* p = new YOLOv8Detector(); delete p;
如果 ~IDetector() 不是虚函数，YOLOv8 的模型资源不会被释放。
```
