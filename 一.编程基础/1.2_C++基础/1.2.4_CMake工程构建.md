# 1.2.4 CMake 工程构建 ⭐⭐⭐

> **机器人视觉定位**：CMake 是所有 C++ 视觉工程的**构建系统**。不会 CMake = 无法编译你的代码 = 代码等于废纸。TensorRT、OpenCV、ROS 等所有依赖都通过 CMake 集成。

---

## 1. CMake 的本质

**CMake 不是编译器，而是一个"生成 Makefile 的工具"。** 它读取 `CMakeLists.txt`，生成编译器能理解的构建规则。

```
CMakeLists.txt（你写的构建配置）
    ↓ cmake ..
Makefile（自动生成的编译规则）
    ↓ make
可执行文件（.exe / .out）
```

---

## 2. 最小 CMakeLists.txt —— 逐行拆解

```cmake
# 指定 CMake 最低版本——低于此版本直接报错
cmake_minimum_required(VERSION 3.16)

# 项目名称和版本——会被编译进可执行文件
project(PerceptionNode VERSION 1.0.0)

# 设置 C++ 标准——视觉项目通常用 C++17
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)  # 强制使用，不支持就报错

# ---- 查找外部依赖 ----
# find_package 会在系统路径中找库的 Config.cmake 或 FindXXX.cmake
find_package(OpenCV REQUIRED COMPONENTS core imgproc dnn highgui)
# REQUIRED：找不到就报错
# COMPONENTS：只需要这些模块

find_package(TensorRT REQUIRED)

# ---- 添加可执行文件 ----
# 源文件列表，可以是一个或多个
add_executable(detection_node
    src/main.cpp
    src/detector.cpp
    src/utils.cpp
)

# ---- 链接库 ----
# PRIVATE：只给当前目标用，不传给依赖此目标的其他目标
target_link_libraries(detection_node PRIVATE
    ${OpenCV_LIBS}          # OpenCV 库
    ${TensorRT_LIBRARIES}   # TensorRT 库
    nvinfer                 # NVIDIA 推理库
    cudart                  # CUDA 运行时
)

# ---- 包含头文件路径 ----
target_include_directories(detection_node PRIVATE
    ${OpenCV_INCLUDE_DIRS}
    ${TensorRT_INCLUDE_DIRS}
    src/                    # 项目自己的头文件路径
)
```

## 3. 常用 CMake 命令速查

```cmake
# ==== 查找系统库 ====
find_package(OpenCV REQUIRED)                     # 系统路径找
find_package(TensorRT REQUIRED PATHS /usr/local/) # 指定路径
find_package(PCL REQUIRED COMPONENTS common io)   # 只找特定模块

# ==== 目标类型 ====
add_executable(my_node main.cpp)                   # 可执行文件
add_library(my_lib SHARED lib.cpp)                 # 动态库（.dll/.so）
add_library(my_lib STATIC lib.cpp)                 # 静态库（.lib/.a）

# ==== 编译选项 ====
target_compile_options(my_node PRIVATE -Wall -O3 -march=native)
target_compile_definitions(my_node PRIVATE USE_CUDA)  # 定义宏

# ==== 子模块 ====
add_subdirectory(src/detection)     # 包含子目录的 CMakeLists.txt

# ==== 安装规则 ====
install(TARGETS my_node DESTINATION bin/)
install(FILES config.yaml DESTINATION config/)
```

## 4. 多模块工程结构

实际机器人感知项目的 CMake 结构：

```
project/
├── CMakeLists.txt                 # 根 CMake
├── src/
│   ├── detection/
│   │   ├── CMakeLists.txt         # 模块 CMake
│   │   ├── detector.cpp
│   │   └── detector.hpp
│   ├── tracking/
│   │   ├── CMakeLists.txt
│   │   ├── tracker.cpp
│   │   └── tracker.hpp
│   └── main.cpp
└── third_party/                    # 第三方依赖
```

```cmake
# 根 CMakeLists.txt
cmake_minimum_required(VERSION 3.16)
project(RobotPerception)

add_subdirectory(src/detection)     # 编译为 detection_lib
add_subdirectory(src/tracking)      # 编译为 tracking_lib

add_executable(perception_node src/main.cpp)
target_link_libraries(perception_node PRIVATE
    detection_lib
    tracking_lib
)
```

```cmake
# src/detection/CMakeLists.txt
add_library(detection_lib STATIC
    detector.cpp
)

target_include_directories(detection_lib PUBLIC ${CMAKE_CURRENT_SOURCE_DIR})
target_link_libraries(detection_lib PUBLIC ${OpenCV_LIBS})
```

## 5. 常见编译错误

| 错误信息 | 原因 | 解决 |
|----------|------|------|
| `fatal error: opencv2/opencv.hpp: No such file` | OpenCV 头文件路径未正确包含 | 检查 `find_package(OpenCV)` 是否成功 |
| `undefined reference to 'cv::imread'` | OpenCV 库未链接 | 添加 `target_link_libraries(... ${OpenCV_LIBS})` |
| `could not find find_package(X)` | 依赖未安装或 CMake 找不到 | 用 `PATHS` 参数指定安装路径 |
| `CMAKE_CXX_STANDARD` 不匹配 | C++ 标准版本冲突 | 统一设为 17 |
