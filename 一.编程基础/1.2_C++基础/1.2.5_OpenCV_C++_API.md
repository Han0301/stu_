## 1. cv::Mat 的本质

**cv::Mat = 一个智能指针管理的内存块 + 描述数据布局的头部信息。**

```
cv::Mat 的内存结构：
┌─────────────────────────┐
│ 头部（固定大小）          │
│   - width, height        │
│   - type（数据类型）      │
│   - channels（通道数）    │
│   - step（行步长）        │
│   - data（指向数据指针）  │ ← 智能指针管理
│   - refcount（引用计数）  │
└─────────────────────────┘
         ↓
┌─────────────────────────┐
│ 图像数据（连续内存块）    │
│ [R][G][B][R][G][B]...   │
│ [R][G][B][R][G][B]...   │
└─────────────────────────┘
```

```cpp
#include <opencv2/opencv.hpp>

// 读取图像 — 返回 cv::Mat
cv::Mat img = cv::imread("image.jpg");
// img.data 指向图像数据的起始地址
// img.rows = 1080, img.cols = 1920, img.channels() = 3

// 访问像素（不推荐——太慢）
for (int r = 0; r < img.rows; r++) {
    for (int c = 0; c < img.cols; c++) {
        cv::Vec3b pixel = img.at<cv::Vec3b>(r, c);
        uchar blue  = pixel[0];
        uchar green = pixel[1];
        uchar red   = pixel[2];
    }
}

// 推荐：通过指针直接操作（快 5~10 倍）
for (int r = 0; r < img.rows; r++) {
    uchar* row_ptr = img.ptr<uchar>(r);  // 第 r 行的起始地址
    for (int c = 0; c < img.cols * 3; c += 3) {
        uchar blue  = row_ptr[c];
        uchar green = row_ptr[c + 1];
        uchar red   = row_ptr[c + 2];
    }
}
```


### 2.2 图像预处理（推理前处理）

```cpp
#include <opencv2/dnn.hpp>

// YOLO 推理的标准预处理 Pipeline
cv::Mat preprocess_for_inference(const cv::Mat& image) {
    cv::Mat blob;
    
    // 1. 缩放到网络输入大小
    cv::Mat resized;
    cv::resize(image, resized, cv::Size(640, 640));
    
    // 2. 转为浮点并归一化到 [0, 1]
    resized.convertTo(resized, CV_32FC3, 1.0 / 255.0);
    
    // 3. 用 dnn::blobFromImage 转为 NCHW 格式
    //    输出形状: (1, 3, 640, 640)
    cv::dnn::blobFromImage(resized, blob);
    
    return blob;
}

// 使用 cv::dnn 模块加载模型做推理
cv::dnn::Net net = cv::dnn::readNet("yolov8.onnx");
net.setPreferableBackend(cv::dnn::DNN_BACKEND_CUDA);
net.setPreferableTarget(cv::dnn::DNN_TARGET_CUDA);

cv::Mat blob = preprocess_for_inference(frame);
net.setInput(blob);
cv::Mat output = net.forward();  // 推理
```

### 2.4 cv::Mat 的拷贝——深拷贝 vs 浅拷贝

```cpp
cv::Mat img = cv::imread("image.jpg");

cv::Mat roi = img(cv::Rect(100, 100, 200, 200));  // 浅拷贝：共享数据
// roi 和 img 指向同一块内存，修改 roi 会影响 img

cv::Mat copy = img.clone();                         // 深拷贝：独立数据
// copy 有自己的内存，修改 copy 不影响 img

cv::Mat copy2;
img.copyTo(copy2);                                  // 也是深拷贝
```

## 面试常考

> **Q1: cv::Mat 的引用计数机制？**

```
cv::Mat 的头部有个 refcount 指针。
浅拷贝时（operator= 或 ROI 操作），
refcount 递增。最后一个 Mat 对象销毁时，数据才被释放。
这就是"写时复制"（COW）——多个 Mat 共享同一份数据，直到有人要修改。
```

> **Q2: 为什么 cv::dnn::blobFromImage 是预处理的关键步骤？**

```
深度学习模型输入是 NCHW 格式：
  N = batch size
  C = channels（3）
  H = height（640）
  W = width（640）
blobFromImage 把 HWC 的 cv::Mat 转成 NCHW 的 blob，
同时完成缩放、减均值、缩放系数等操作。
```
