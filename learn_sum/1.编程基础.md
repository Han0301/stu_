# 一、编程基础

> **与机器人视觉感知的关联**：编程是落地一切算法的载体。机器人视觉系统涉及**数据采集（传感器驱动）→ 预处理（图像/点云处理）→ 推理（深度学习模型）→ 后处理（检测解析/跟踪关联）→ 融合（多传感器）→ 控制输出（ROS 消息）** 全链路，每一环都需要扎实的编程能力。20K 岗位要求"能独立开发维护感知模块"，本质要求是**写出的代码能上机器人稳定运行**。

| ----------- | -------------------------------------------------------------- | --------------------------- | ---- |
| **基本语法**    | 变量/类型/流程控制/函数/类/模块                                             | 编写训练脚本、数据处理 Pipeline        | ⭐⭐⭐  |
| **装饰器**     | `@staticmethod/@classmethod`、带参数装饰器、`functools.wraps`          | 推理耗时统计、模型加载缓存、日志打点          | ⭐⭐   |

| **上下文管理器**  | `with` 语句、`__enter__`/`__exit__`                               | 文件/视频流/网络资源的安全释放、推理计时上下文    | ⭐⭐   |
| **多进程/多线程** | `multiprocessing.Pool`、`concurrent.futures`、`threading`、GIL 机制 | 多路视频流并行处理、异步模型推理、数据加载加速     | ⭐⭐⭐  |
| **类型注解**    | `typing`（List/Dict/Optional/Union/TypeVar）                     | 大型项目代码可维护性、API 接口文档化        | ⭐⭐   |
| **异常处理**    | `try/except/finally`、自定义异常                                     | 传感器断连/模型加载失败等异常场景的容错        | ⭐⭐   |
| **文件 I/O**  | `json/yaml/protobuf` 序列化、`pathlib`                             | 配置文件读写、标注数据加载、模型权重保存        | ⭐⭐⭐  |

### 针对机器人视觉的进阶要求

- **`__slots__`**：大量检测框/跟踪目标对象时节省内存
- **`numpy` 向量化**：避免 for 循环处理图像/点云数据，这是性能关键
- **`ctypes`/`pybind11`**：Python 调用 C++ 推理库的接口方式
- **`asyncio`**：异步 I/O 处理多个传感器数据流

## 1.5 ROS1/ROS2 — 机器人系统集成 ⭐⭐⭐

这是机器人视觉感知区别于通用 CV 方向最显著的技能模块。面试中会直接问"你用过 ROS 的哪些功能"。

| 知识点            | 详细内容                                              | 与机器人视觉的关联                   | 掌握程度 |
| -------------- | ------------------------------------------------- | --------------------------- | ---- |
| **核心通信机制**     | 话题(Topic)发布/订阅、服务(Service)客户端/服务器、动作(Action)      | 感知结果（检测框/轨迹）发布到可视化话题、调用标定服务 | ⭐⭐⭐  |
| **msg/srv 定义** | 自定义消息类型（检测框、跟踪结果、3D 姿态）                           | 定义感知模块输出的数据结构               | ⭐⭐   |
| **TF 坐标变换**    | `tf2`、`lookupTransform`、`transformPointCloud`     | 多传感器坐标系统一、将检测结果从相机系转到基坐标系   | ⭐⭐⭐  |
| **bag 工具**     | `rosbag record/play`、bag 解析与转换                    | 采集路测数据、回放离线调试算法、构造测试集       | ⭐⭐⭐  |
| **URDF/SDF**   | 机器人模型描述、传感器安装位置定义                                 | 定义相机/LiDAR 在机器人上的安装位置       | ⭐⭐   |
| **RViz 可视化**   | `Marker`/`MarkerArray`、`Image`/`PointCloud2` 话题显示 | 实时可视化检测框、跟踪轨迹、点云、深度图        | ⭐⭐⭐  |
| **Nodelet**    | 零拷贝传输、进程内通信                                       | 多传感器高频数据的低延迟处理              | ⭐    |
| **ROS2 差异**    | DDS 中间件、`rclcpp`/`rclpy`、生命周期节点                   | 新一代机器人系统迁移趋势                | ⭐⭐   |

### 必须完成的 ROS 实践

1. **写一个视觉感知节点**：订阅 `/camera/image_raw` → 运行模型推理 → 发布检测结果 `/detections`
2. **多传感器融合节点**：订阅 image + LiDAR 点云 + IMU，发布融合后的障碍物列表
3. **理解 ROS 时间机制**：`ros::Time::now()` vs 传感器时间戳、TF 时间旅行
