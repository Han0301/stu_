# 机器人视觉感知工程师 · 知识清单总览

> 本清单聚焦机器人视觉感知方向的**核心知识模块**，每个模块列出关键知识点及其与机器人视觉的关联，以及需要掌握的程度等级。

| 等级         | 含义                                 |
| ---------- | ---------------------------------- |
| ⭐⭐⭐ **精通** | 能闭眼徒手写代码/推导公式，面试能讲 15 分钟，能独立解决工程问题 |

## 知识模块清单

### 一、编程基础

- Python 核心语法与高级特性（装饰器、生成器、多线程/进程）
- C++ 基础（指针、STL、多态、CMake）— 部署端需求
- 数据结构与算法（LeetCode 中等水平）
- NumPy 向量化编程（广播、einsum、轴操作）— 预处理/后处理核心
- **ROS1/ROS2**（节点/话题/服务/TF/bag）— 机器人系统集成必备

### 二、数学基础

- 线性代数（矩阵运算、SVD、特征分解）— 图像变换/本质矩阵
- **李群李代数** SO(3)/SE(3) — SLAM 位姿优化
- **四元数** — 姿态表示/IMU 融合
- 最优化方法（高斯-牛顿、LM、BA）— SLAM 后端
- **卡尔曼滤波 KF/EKF/UKF** — 状态估计/多目标跟踪
- 三维空间刚体几何（齐次坐标、欧拉角）— 坐标系转换

### 三、数字图像处理

- 图像滤波（高斯/中值/双边）— 预处理去噪
- 边缘检测（Canny）— 传统特征提取
- 几何变换（仿射/透视）— 数据增强/图像配准
- OpenCV 熟练使用 — 日常 80% 图片处理工作

### 四、深度学习基础

- CNN 原理（卷积/池化/感受野/参数量计算）
- 激活函数、归一化（BN/LN/GN 对比）
- 损失函数（Cross-Entropy/Focal Loss/IoU Loss/Smooth L1）
- 优化器（SGD+Momentum/Adam/AdamW/余弦退火）
- 数据增强（Mosaic/MixUp/Albumentations）
- 训练技巧（AMP/EMA/DDP/梯度裁剪）
- **PyTorch 精通**（nn.Module/DataLoader/torch.jit/ONNX 导出）

### 五、2D 视觉感知 ← 岗位核心产出

- **图像分类**：ResNet/MobileNet/EfficientNet/ViT，fine-tune 流程
- **目标检测 ⭐⭐⭐**：YOLO 系列（v5/v8/v9/v10）、Faster R-CNN、DETR；正负样本分配（ATSS/SimOTA）；NMS；mAP 评估
- **语义/实例分割**：UNet/Mask R-CNN 原理
- **多目标跟踪 ⭐⭐⭐**：SORT/DeepSORT → ByteTrack；卡尔曼滤波+匈牙利匹配

### 六、3D 视觉与空间感知 ← 机器人视觉核心壁垒

- **相机模型**：针孔模型、畸变、内参/外参
- **多视图几何**：对极几何、本质矩阵、PnP、三角化、BA 优化
- **立体视觉**：双目匹配、视差→深度
- **点云处理**：PCL、体素降采样、PointNet/PointNet++
- **视觉 SLAM ⭐⭐⭐**：ORB-SLAM3、VINS-Mono（IMU预积分+边缘化+滑动窗口）
- **3D 目标检测**：BEVDet/BEVFormer、PointPillars/CenterPoint

### 七、多传感器融合

- **传感器标定**：相机内参（张正友）、相机-IMU 联合标定（Kalibr）
- **手眼标定**：Eye-in-Hand/Eye-to-Hand、AX=XB
- **IMU 模型与预积分**：加速度计/陀螺仪、Allan 方差
- **松耦合 vs 紧耦合融合**：KF 滤波 vs 联合 BA 优化
- **时空同步**：硬件触发/软件对齐

### 八、模型部署与优化

- **ONNX**：`torch.onnx.export`、动态轴、算子兼容性
- **TensorRT ⭐⭐⭐**：FP16/INT8 量化、Layer Fusion、Plugin 自定义算子
- **量化技术**：PTQ vs QAT、KL 散度校准
- **NVIDIA Jetson**：Orin/AGX 边缘部署
- **Profiling**：Nsight Systems、trtexec 性能分析

### 九、工程工具链

- **Docker**：镜像构建、GPU 挂载、ROS 容器化
- **Git**：分支策略、rebase、submodule
- **Linux**：命令行、systemd、cmake、gdb
- **实验管理**：W&B/MLflow、Hydra 配置系统

### 十、面试高频手撕代码

- NMS 实现（含 IoU 计算）— ⭐⭐⭐
- 一维卡尔曼滤波预测+更新 — ⭐⭐⭐
- 欧拉角↔旋转矩阵↔四元数互转 — ⭐⭐⭐
- PnP 原理与 RANSAC 流程 — ⭐⭐
- 三角化求 3D 点 — ⭐⭐
- 手写高斯滤波 / Sobel — ⭐⭐
- LeetCode 中等（反转链表/两数之和/LRU）— ⭐⭐

---

> **优先级建议**：目标检测（YOLO 源码）+ 多目标跟踪（ByteTrack）+ SLAM（ORB-SLAM3/VINS-Mono）+ 模型部署（TensorRT）是机器人视觉感知岗位面试最高频的四大模块。
