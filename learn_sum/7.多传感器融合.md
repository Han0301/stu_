# 七、多传感器融合

> **与机器人视觉感知的关联**：单一传感器总有局限性——**相机在低光/无纹理环境下失效，IMU 有漂移，LiDAR 在雨雪天退化**。多传感器融合通过互补传感器的优势，提供**更鲁棒、更连续、更准确**的环境感知。这是机器人视觉感知从"实验室 Demo"走向"产品级部署"的必经之路。20K 岗位通常要求"熟悉多传感器融合算法，有 IMU+Camera 融合经验"。

---

## 7.1 传感器标定 ⭐⭐⭐

标定是所有融合的前提——传感器之间如果没有精确的空间和时间对齐，融合反而会降低性能。

### 7.1.1 相机内参标定

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **张正友标定法** | 棋盘格 + 单应矩阵 + 内参约束 + 畸变参数估计 | ⭐⭐⭐ |
| **标定板设计** | 棋盘格 vs 圆点阵、编码点靶标、AprilTag | ⭐⭐ |
| **重投影误差** | 标定质量的核心指标，通常要求 < 0.5 pixel | ⭐⭐⭐ |
| **标定工具** | OpenCV `calibrateCamera`、MATLAB Calibrator、Kalibr、Matlab 单目标定 | ⭐⭐⭐ |
| **鱼眼相机标定** | 不同畸变模型（Kannala-Brandt / Scaramuzza） | ⭐ |

### 7.1.2 相机-IMU 联合标定 ⭐⭐⭐

这是 VIO/VINS 系统中最关键的标定步骤。

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **Kalibr 工具** | ETH 开发的标定工具箱，支持 camera-imu 联合标定 | ⭐⭐⭐ |
| **标定流程** | 录制相机+IMU 数据 → Kalibr 离线优化 → 输出变换矩阵 T_ic 和时间延迟 td | ⭐⭐⭐ |
| **标定参数** | 外参 T_ic（IMU→相机变换）、时间偏移 td、IMU 噪声密度 | ⭐⭐⭐ |
| **可观测性** | 标定板的充分激励（旋转+平移+不同速度） | ⭐⭐ |

```text
Kalibr 标定流程：
    1. 准备 AprilGrid 标定板（打印后贴平）
    2. 录制 ROS bag（相机图像 + IMU 数据，至少 2 分钟，包含充分运动）
    3. 运行 kalibr_calibrate_imu_camera
    4. 检查标定结果：
       - 重投影误差 < 1 pixel
       - T_ic 的旋转分量稳定（每次重标定差异 < 1°）
       - 时间偏移 td 稳定
```

### 7.1.3 手眼标定 ⭐⭐

机械臂视觉的核心标定。

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **Eye-in-Hand** | 相机装在机械臂末端 → 标定 camera→end_effector | ⭐⭐ |
| **Eye-to-Hand** | 相机固定在外界 → 标定 camera→robot_base | ⭐⭐ |
| **AX=XB 求解** | 用多组机械臂位姿和相机位姿求解（Tsai-Lenz 等） | ⭐⭐ |
| **工具** | `easy_handeye`（ROS 手眼标定工具包） | ⭐⭐ |

### 7.1.4 相机-LiDAR 联合标定

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **3D-2D 对应** | LiDAR 点云边缘点 → 图像棋盘格角点对应 | ⭐⭐ |
| **标定板检测** | 用反射强度区分标定板、提取边界 | ⭐⭐ |
| **工具** | `lidar_camera_calibration`（ROS 包）、Autoware 标定工具 | ⭐⭐ |

## 7.2 IMU 原理与模型 ⭐⭐⭐

IMU 是机器人视觉融合中最广泛使用的辅助传感器。

### 7.2.1 IMU 测量模型

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **加速度计** | 测量比力（specific force）= 加速度 - 重力 | ⭐⭐⭐ |
| **陀螺仪** | 测量角速度 | ⭐⭐⭐ |
| **测量噪声** | 白噪声 n (高斯) + 随机游走 b (Brown 运动) | ⭐⭐⭐ |
| **Allan 方差** | 分析 IMU 噪声特性的标准方法（确定 n 和 b 的数值） | ⭐⭐ |

```text
IMU 测量模型：
    ω_meas = ω_true + b_g + n_g       (陀螺仪)
    a_meas = a_true - g + b_a + n_a   (加速度计)
    
    其中:
    n_g, n_a ~ N(0, σ²)        → 白噪声（高斯，高频）
    b_g, b_a 随机游走           → 偏置（低频，缓慢漂移）
```

### 7.2.2 IMU 运动学 ⭐⭐⭐

```text
从 IMU 测量恢复姿态/速度/位置（离散时间递推）：
    
    姿态更新: q_{k+1} = q_k ⊗ exp(ω * Δt/2)
    速度更新: v_{k+1} = v_k + (R(q_k) * a_meas - g) * Δt
    位置更新: p_{k+1} = p_k + v_k * Δt + 0.5 * (R(q_k) * a_meas - g) * Δt²
```

### 7.2.3 IMU 预积分 ⭐⭐⭐（VINS 核心）

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **为什么要预积分？** | 避免每次优化时重新积分，预积分结果是两帧之间的**相对运动增量** | ⭐⭐⭐ |
| **连续时间形式** | dΔp/dt、dΔv/dt、dΔq/dt 的微分方程 | ⭐⭐⭐ |
| **离散时间形式** | 欧拉积分 / 中值积分（VINS 用中值法更准） | ⭐⭐⭐ |
| **预积分噪声传递** | 协方差矩阵的递推（用于信息矩阵） | ⭐⭐ |
| **偏置更新** | 预积分值对偏置的 Jacobian（偏置变化时不用重新预积分） | ⭐⭐⭐ |

## 7.3 融合策略 ⭐⭐⭐

### 7.3.1 松耦合融合

```text
松耦合：各传感器独立处理 → 在状态估计层融合
    
    相机 → VO/vSLAM → 输出位姿 ┐
                                ├──→ 卡尔曼滤波融合 → 最终状态
    IMU  → IMU 积分 → 输出位姿 ┘
    
    优点: 各模块解耦，可独立开发/调试
    缺点: 各模块之间的信息交互有限（观测已被处理成位姿，损失了信息）
```

### 7.3.2 紧耦合融合 ⭐⭐⭐

```text
紧耦合：各传感器原始观测 → 同一个优化问题联合求解
    
    相机 → 特征点(原始观测) ┐
                            ├──→ 联合 BA: min(重投影误差 + IMU预积分误差)
    IMU  → 预积分(原始观测) ┘
    
    优点: 信息损失最小，精度最高
    缺点: 计算量大，实现复杂
```

### 7.3.3 滤波器 vs 优化器

| 方法 | 代表 | 优缺点 | 适用场景 |
|------|------|--------|---------|
| **扩展卡尔曼滤波 EKF** | MSCKF | 计算量小、但线性化误差累积 | 计算资源有限的嵌入式 |
| **滑动窗口优化** | VINS-Mono、OKVIS | 精度高、有边缘化策略 | 大多数机器人视觉系统 |
| **全图优化** | ORB-SLAM3（全局 BA） | 精度最高、计算量大 | 非实时/离线处理 |

## 7.4 时空同步 ⭐⭐

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **硬件同步** | 相机硬件触发信号给到 IMU/LiDAR，时间戳硬件对齐 | ⭐⭐ |
| **软件同步** | 各传感器用同一系统时钟、网络时间协议 NTP | ⭐⭐ |
| **时间戳管理** | ROS `time` + `TimeSynchronizer` / `message_filters::sync` | ⭐⭐⭐ |
| **时间偏移估计** | Kalibr 中估计 camera-imu 的时间延迟 td | ⭐⭐⭐ |
| **时间同步的重要性** | 1ms 的时间不同步 → 运动物体的位置误差可能达数厘米 | ⭐⭐⭐ |

### ROS 中的时间同步实践

```python
import message_filters
from sensor_msgs.msg import Image, Imu

def callback(image_msg, imu_msg):
    # image_msg.header.stamp 和 imu_msg.header.stamp 已对齐
    process(image_msg, imu_msg)

image_sub = message_filters.Subscriber('/camera/image_raw', Image)
imu_sub = message_filters.Subscriber('/imu/data_raw', Imu)
ts = message_filters.ApproximateTimeSynchronizer(
    [image_sub, imu_sub], queue_size=10, slop=0.01  # slop=10ms 容忍
)
ts.registerCallback(callback)
```

## 7.5 多传感器数据预处理

### 7.5.1 传感器特性对比

| 传感器 | 优点 | 缺点 | 互补作用 |
|--------|------|------|---------|
| **单目相机** | 低成本、纹理丰富 | 无尺度、低光差、运动模糊 | IMU 提供尺度+短时位姿 |
| **双目相机** | 有尺度、被动 | 基线限制距离、计算量大 | IMU 辅助立体匹配 |
| **IMU** | 高频(100-1000Hz)、短时精准 | 漂移严重、无绝对位置 | 相机校正漂移 |
| **LiDAR** | 精确深度、不受光照影响 | 稀疏、无纹理、贵 | 图像提供稠密语义 |
| **深度相机** | 稠密深度、低成本 | 室内/近距有效、受阳光干扰 | 和 RGB 做 RGB-D SLAM |

### 7.5.2 传感器故障检测

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **相机丢帧检测** | 时间戳间隔异常 → 相机故障 | ⭐⭐ |
| **IMU 静止检测** | 加速度方差 < 阈值 → 静止状态 → 零速修正 | ⭐⭐⭐ |
| **IMU 饱和** | 测量值超出量程 → 高动态运动 | ⭐⭐ |
| **运动退化检测** | 纯旋转/纯平移 → 某些自由度不可观 | ⭐⭐ |

> **学习路径建议**：
> 1. **第 1 周**：理解 IMU 测量模型 + Kalibr 标定原理，用学校/自己的设备做一次 camera-imu 标定
> 2. **第 2 周**：精读 VINS-Mono 论文的 IMU 预积分部分，对照代码理解每一行预积分公式
> 3. **第 3 周**：搭建一个 ROS 传感器数据采集系统（相机 + IMU），用 bag 记录数据并做时间同步分析
> 4. **第 4 周**：理解 Kalibr 源码的优化目标函数（重投影误差 + IMU 误差 + 时间偏移）
> 5. **实践项目**：用 Realsense D435i（自带 IMU）或手持手机（利用手机 IMU）运行 VINS-Mono，体验 VIO 的实际效果
