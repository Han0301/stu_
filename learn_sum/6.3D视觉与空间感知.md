# 六、3D 视觉与空间感知

> **与机器人视觉感知的关联**：这是**机器人视觉感知区别于普通 CV 方向最核心的模块**。2D 视觉只能回答"图像中有什么"，3D 视觉才能回答"物体在空间中的什么位置、什么姿态"。无论是**机械臂抓取**（需要 6D 姿态）、**自主导航**（需要 3D 地图和定位）、还是**自动驾驶**（需要 3D 障碍物检测与跟踪），核心都在于从 2D 图像/3D 点云中**恢复空间信息**。这个模块的知识深度直接决定了你能在机器人视觉领域走多远。

## 6.1 相机模型 ⭐⭐⭐

这是所有 3D 视觉的起点，必须达到**闭眼推导**的程度。

### 6.1.1 针孔相机模型

| 知识点 | 详细内容 | 与机器人视觉的关联 | 掌握程度 |
|--------|---------|------------------|---------|
| **投影方程** | `z * [u, v, 1]^T = K * [R\|t] * [X, Y, Z, 1]^T` | **所有 3D-2D 关系的核心公式** | ⭐⭐⭐ |
| **内参矩阵 K** | `[fx, 0, cx; 0, fy, cy; 0, 0, 1]` | fx/fy 是焦距（像素单位），cx/cy 是光心偏移 | ⭐⭐⭐ |
| **归一化平面** | `[x, y, 1]^T = [X/Z, Y/Z, 1]^T`（相机系） | 连接 3D 点和 2D 点的中间桥梁 | ⭐⭐⭐ |
| **外参矩阵 [R\|t]** | 世界系 → 相机系的刚体变换 | 相机在机器人上的安装位置和朝向 | ⭐⭐⭐ |
| **投影矩阵 P** | `P = K[R\|t]`，3×4 矩阵 | 直接从世界 3D 点 → 像素 2D 点 | ⭐⭐⭐ |

### 6.1.2 畸变模型 ⭐⭐⭐

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **径向畸变** | `x_dist = x(1 + k1*r² + k2*r⁴ + k3*r⁶)`（桶形/枕形） | ⭐⭐⭐ |
| **切向畸变** | `x_dist = x + 2*p1*x*y + p2*(r²+2x²)`（镜头装配偏差） | ⭐⭐⭐ |
| **去畸变流程** | 已知畸变系数 → 计算无畸变图 → `cv2.initUndistortRectifyMap` + `remap` | ⭐⭐⭐ |
| **畸变对感知的影响** | 不做去畸变 → 边缘处的目标位置偏差可达几十像素 → PnP/三角化全部出错 | ⭐⭐⭐ |

### 6.1.3 相机标定实践 ⭐⭐⭐

```text
必须亲手完成一次相机标定，理解每一行代码的含义：
    1. 拍摄 15-20 张棋盘格不同角度图像
    2. cv2.findChessboardCorners → 角点亚像素优化
    3. cv2.calibrateCamera → 输出 K, distCoeffs, rvecs, tvecs
    4. 验证: 重投影误差 < 0.5 pixel
    5. 用标定结果去畸变 → 观察边缘直线是否变直
```

## 6.2 多视图几何 ⭐⭐⭐

这是 3D 从图像中恢复的核心理论基础。

### 6.2.1 对极几何

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **对极约束** | `x₂^T * E * x₁ = 0` 或 `x₂^T * F * x₁ = 0` | ⭐⭐⭐ |
| **本质矩阵 E** | `E = t^× R`，5 自由度（3 旋转 + 2 平移方向） | ⭐⭐⭐ |
| **基础矩阵 F** | `F = K⁻ᵀ E K⁻¹`，7 自由度 | ⭐⭐⭐ |
| **单应矩阵 H** | 纯旋转/平面场景下的 3×3 变换 | ⭐⭐⭐ |
| **八点法** | 至少 8 对匹配点解 E/F，SVD 解 A*h=0 | ⭐⭐⭐ |
| **五点法** | 最少 5 对点解 E（Nister 方法，ORB-SLAM 使用） | ⭐⭐ |
| **本质矩阵分解** | E = U diag(σ,σ,0) V^T → 4 组 (R,t) 解 | ⭐⭐⭐ |

#### 从本质矩阵恢复 R,t（面试常考）

```text
E = U Σ V^T, Σ = diag(σ, σ, 0)

两种可能的旋转:
R₁ = U * W * V^T,  R₂ = U * W^T * V^T
其中 W = [0, -1, 0; 1, 0, 0; 0, 0, 1]

带符号的平移:
t₁ = U[:, 2],  t₂ = -U[:, 2]

4 种组合 (R₁,R₂) × (t₁,t₂)，通过三角化点必须在两个相机前方选唯一解
```

### 6.2.2 PnP 求解 ⭐⭐⭐

已知 3D-2D 对应点，求相机位姿 [R|t]。

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **P3P** | 3 个点 + 1 个验证点，解多项式方程 | ⭐⭐ |
| **EPnP** | 4 个控制点做加权和，O(n) 复杂度 | ⭐⭐⭐ |
| **DLT** | 直接线性变换（6 对点以上），线性最小二乘 | ⭐⭐ |
| **迭代 PnP** | L-M 优化最小化重投影误差 | ⭐⭐⭐ |
| **RANSAC** | 随机采样 4 对点求解 + 一致性检验 | ⭐⭐⭐ |
| **Ceres/g2o** | BA 框架下的 PnP 求解（自动求导） | ⭐⭐ |

### 6.2.3 三角化

从两个或更多视图恢复 3D 点位置。

```text
已知: 两个视图的相机位姿 [R₁|t₁], [R₂|t₂] 和匹配点 (u₁,v₁), (u₂,v₂)
求: 3D 点位置 (X,Y,Z)

解法: 构造线性方程 A * X = 0 (SVD 求解)
    或最优三角化（考虑噪声的非线性优化）
```

### 6.2.4 Bundle Adjustment (BA) ⭐⭐⭐

SLAM 后端的核心优化手段。

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **重投影误差** | `e = u - K[R\|t]P`（观测像素 - 投影像素） | ⭐⭐⭐ |
| **BA 优化问题** | `min Σ ||u_ij - K[R_i\|t_i]P_j||²` | ⭐⭐⭐ |
| **Ceres Solver** | Google 的自动求导 BA 库、`AutoDiffCostFunction` | ⭐⭐⭐ |
| **g2o** | 图优化框架、顶点（位姿/点）+ 边（观测） | ⭐⭐⭐ |
| **Schur 消元** | 利用海森矩阵的稀疏结构加速求解 | ⭐⭐ |
| **边缘化** | 将旧状态边缘化为先验（VINS 的滑动窗口） | ⭐⭐ |

## 6.3 立体视觉与深度估计

### 6.3.1 双目立体匹配

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **极线校正** | 双目图像行对齐 → 匹配搜索从 2D 降到 1D | ⭐⭐⭐ |
| **视差计算** | `d = x_l - x_r`，通过块匹配沿极线搜索 | ⭐⭐⭐ |
| **深度与视差** | `Z = f * B / d`（f=焦距, B=基线） | ⭐⭐⭐ |
| **SGM 算法** | 半全局匹配：像素代价 + 多方向平滑约束 | ⭐⭐ |
| **双目深度评估** | 离基线越远精度越低、纹理越少处误差越大 | ⭐⭐ |

### 6.3.2 单目深度估计

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **监督深度估计** | 有 GT 深度训练（如 NYUv2） | ⭐ |
| **自监督深度估计** | MonoDepth2: 用双目/时序光度一致性损失训练 | ⭐⭐ |
| **深度补全** | 稀疏 LiDAR 点云 → 稠密深度图（RGB 引导） | ⭐⭐ |

> **机器人视觉提示**：双目立体在室内/中距离场景效果好，单目深度估计精度不够但成本低。工业机器人大都使用**双目+LiDAR**的组合。

## 6.4 点云处理 ⭐⭐

### 6.4.1 点云基础

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **点云表示** | (x,y,z) 坐标 + 可选属性（RGB/反射强度/法向量） | ⭐⭐⭐ |
| **PCL 库** | `pcl::PointCloud`、`pcl::visualization` | ⭐⭐⭐ |
| **体素降采样** | VoxelGrid：划分网格后取质心（减少点数量但保形状） | ⭐⭐⭐ |
| **直通滤波** | 按坐标轴范围去掉远距离噪声点 | ⭐⭐⭐ |
| **统计滤波** | 统计邻域距离分布，去除离群点（激光雷达的噪点） | ⭐⭐ |
| **半径滤波** | 半径内点数少于阈值 → 去除（孤立噪点） | ⭐⭐ |
| **法向量估计** | PCA 分解邻域的协方差矩阵 → 最小特征值对应法向 | ⭐⭐ |

### 6.4.2 点云深度学习

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **PointNet** | 共享 MLP + 最大池化（对称函数保证置换不变性） | ⭐⭐⭐ |
| **PointNet++** | 分层 PointNet（多尺度分组MSG/MRG）+ FPS 采样 | ⭐⭐⭐ |
| **体素方法** | VoxelNet：将点云转体素 → 3D Conv → RPN | ⭐⭐ |
| **PointPillars** | 垂直方向压缩成 Pillar → 2D Backbone（效率高） | ⭐⭐⭐ |
| **CenterPoint** | 基于中心点检测的 3D 检测器 | ⭐⭐ |

### 6.4.3 点云配准

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **ICP** | 迭代最近点：Euclidean 距离找最近点 → SVD 求解 R,t → 迭代 | ⭐⭐⭐ |
| **Point-to-Plane ICP** | 点到面距离（比点到点收敛更快） | ⭐⭐ |
| **NDT** | 正态分布变换：概率密度函数配准（更快、更鲁棒） | ⭐⭐ |
| **ICP 初始化** | 要求初始位姿不能偏差太大，否则收敛到局部最优 | ⭐⭐⭐ |

### 点云在机器人视觉中的应用

- **3D 目标检测**：用 LiDAR 点云检测障碍物（不受光照影响）
- **地面分割**：识别可通行区域（自动驾驶/室内导航）
- **SLAM 建图**：点云地图用于定位和路径规划
- **物体定位**：用点云 ICP 配准获取物体精确 6D 位姿

## 6.5 视觉 SLAM ⭐⭐⭐

这是机器人视觉感知的**最高阶能力**，也是 20K+ 岗位与普通 CV 岗位的分水岭。

### 6.5.1 SLAM 基础框架

```text
SLAM = Simultaneous Localization and Mapping
       ┌──────────────┐
       │   传感器数据    │ ← 相机/IMU/LiDAR
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │  前端 VO/VIO  │ ← 帧间位姿估计 (PnP/光流/IMU预积分)
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │  后端优化(BA)  │ ← 局部/全局 BA (Ceres/g2o)
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │   回环检测     │ ← 仅视觉的 SLAM 特有 (DBoW2)
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │   地图构建     │ ← 稀疏/稠密/语义地图
       └──────────────┘
```

### 6.5.2 ORB-SLAM3 ⭐⭐⭐

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **ORB 特征** | FAST 角点 + BRIEF 描述子（旋转不变性+rBRIEF 改进） | ⭐⭐⭐ |
| **共视图** | 关键帧之间的共视关系图（优化和回环的基础） | ⭐⭐⭐ |
| **本质图** | 共视图的简化版本（单应+基线的边），用于回环矫正 | ⭐⭐ |
| **关键帧选取策略** | 共视点数阈值、最近参考帧距离 | ⭐⭐⭐ |
| **四线程** | 追踪 + 局部建图 + 回环检测 + 全局 BA | ⭐⭐⭐ |
| **IMU 支持** | ORB-SLAM3 支持视觉 + IMU 紧耦合 | ⭐⭐ |
| **Atlas 地图集** | 多地图系统（跟踪丢失后重新初始化，重定位后合并） | ⭐⭐ |

### 6.5.3 VINS-Mono ⭐⭐⭐（面试高频）

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|
| **IMU 测量模型** | `a_m = a + b_a + n_a`，`ω_m = ω + b_g + n_g` | ⭐⭐⭐ |
| **IMU 预积分** | 在两帧图像之间对 IMU 数据预积分，避免重复积分 | ⭐⭐⭐ |
| **预积分公式** | 位置/速度/旋转的增量形式（连续和离散两种推导） | ⭐⭐⭐ |
| **滑动窗口** | 只维护最近 N 帧，旧帧边缘化 | ⭐⭐⭐ |
| **边缘化（Marginalization）** | 将旧状态转为先验约束（舒尔补） | ⭐⭐⭐ |
| **初始化** | 视觉 SfM + IMU 对齐（重力/尺度/速度/偏置估计） | ⭐⭐⭐ |
| **紧耦合 VIO** | 视觉重投影 + IMU 预积分在同一个 BA 中联合优化 | ⭐⭐⭐ |

### 6.5.4 直接法 SLAM

| 知识点 | 详细内容 | 掌握程度 |

### 6.5.5 深度学习 SLAM

| 知识点 | 详细内容 | 掌握程度 |
|--------|---------|---------|

### 6.5.6 SLAM 评估指标

| 指标 | 含义 | 工具 |
|------|------|------|
| **ATE (绝对轨迹误差)** | 估计轨迹与真值轨迹的对齐后 RMSE | `evo_ape` |
| **RPE (相对位姿误差)** | 固定时间间隔的位姿变化误差 | `evo_rpe` |

| **evo 工具** | `pip install evo`，SLAM 评估标准工具 | ⭐⭐⭐ 必须会用 |

## 6.7 坐标系转换 ⭐⭐⭐

机器人视觉中最容易出错但必须掌握的基础。

```text
机器人涉及多个坐标系，必须能熟练转换：
    世界坐标系 (world) ├── 机器人基坐标系 (base)
                      │       ├── 相机坐标系 (camera)
                      │       │       ├── 图像坐标系 (image)
                      │       │       └── 像素坐标系 (pixel)
                      │       ├── LiDAR 坐标系 (lidar)
                      │       ├── IMU 坐标系 (imu)
                      │       └── 机械臂末端坐标系 (end_effector)
```

### 坐标系转换的 ROS 实践（必须掌握）

```python
import tf2_ros
import tf2_geometry_msgs

# 在 ROS 中查询任意两个坐标系的变换
tf_buffer = tf2_ros.Buffer()
listener = tf2_ros.TransformListener(tf_buffer)
try:
    trans = tf_buffer.lookup_transform('base_link', 'camera_link', rospy.Time(0))
    # trans.transform.translation → 平移
    # trans.transform.rotation → 四元数旋转
except (tf2_ros.LookupException, tf2_ros.ConnectivityException,
        tf2_ros.ExtrapolationException):
    pass
```
