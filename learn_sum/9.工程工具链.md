# 九、工程工具链

> **与机器人视觉感知的关联**：工程工具链决定了你的算法能否**稳定、高效、可复现**地在机器人上运行。Docker 保证开发环境和部署环境一致，Git 管理代码和模型版本，Linux 是机器人系统的默认操作系统（ROS 只支持 Linux），实验管理工具帮你追踪每一次训练的超参和结果。20K 岗位要求"有良好的工程习惯"，本质上就是会用这些工具。

---

## 9.1 Docker ⭐⭐⭐

Docker 是解决"在我电脑上能跑"问题的标准方案。

| 知识点 | 详细内容 | 与机器人视觉的关联 | 掌握程度 |
|--------|---------|------------------|---------|
| **Dockerfile 编写** | `FROM`/`RUN`/`COPY`/`WORKDIR`/`ENTRYPOINT`/`CMD` | 构建包含 CUDA+PyTorch+TensorRT 的镜像 | ⭐⭐⭐ |
| **docker build** | `docker build -t image:tag .`、层缓存优化 | 每次修改只重新构建变化的层 | ⭐⭐ |
| **docker run** | `--gpus all`、`-v` 挂载代码和数据、`-p` 端口映射 | 运行带 GPU 支持的容器 | ⭐⭐⭐ |
| **docker-compose** | 多容器编排（ROS Master + 感知 + 可视化） | 多节点机器人系统 | ⭐⭐ |
| **Docker Hub / 私有仓库** | `docker push/pull`、镜像版本管理 | 分发给团队/部署到机器人 | ⭐⭐ |
| **ROS Docker 镜像** | `osrf/ros:noetic-desktop-full`、ROS2 镜像 | ROS 开发环境的标准化 | ⭐⭐⭐ |

### 机器人视觉的典型 Docker 镜像

```dockerfile
# jetson 部署专用镜像
FROM nvcr.io/nvidia/tensorrt:24.12-py3

RUN apt-get update && apt-get install -y \
    ros-noetic-desktop-full \
    python3-pip \
    && rm -rf /var/lib/apt/lists/*

RUN pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
RUN pip install onnx onnxruntime-gpu numpy opencv-python

WORKDIR /workspace
COPY . /workspace/

CMD ["roslaunch", "my_perception", "perception.launch"]
```

### 必须掌握的 Docker 命令

```bash
# 常用命令清单
docker images                     # 查看镜像
docker ps -a                      # 查看容器（包括已停止的）
docker exec -it container_id bash # 进入运行中的容器
docker logs container_id          # 查看容器日志
docker cp src container:dest      # 复制文件到容器
docker system prune               # 清理无用数据
```

## 9.2 Git ⭐⭐⭐

| 知识点 | 详细内容 | 与机器人视觉的关联 | 掌握程度 |
|--------|---------|------------------|---------|
| **基本操作** | `add/commit/push/pull/status/log` | 日常编码管理 | ⭐⭐⭐ |
| **分支策略** | `feature/release/hotfix` 分支、GitFlow、GitHub Flow | 多人协作开发感知模块 | ⭐⭐ |
| **rebase vs merge** | rebase 线性历史 vs merge 保留分支结构 | 保持提交历史整洁 | ⭐⭐ |
| **cherry-pick** | 挑出某次提交到当前分支 | 紧急 bugfix 移植 | ⭐⭐ |
| **submodule** | 引用第三方库（如 ORB-SLAM3 的第三方依赖） | 管理大型项目依赖 | ⭐⭐ |
| **.gitignore** | 忽略 `.pt`/`onnx`/`trt`/`__pycache__`/`data` 等 | 避免大文件进仓库 | ⭐⭐⭐ |
| **Git LFS** | 大文件存储（模型权重、数据集、bag 文件） | 管理 >100MB 的模型文件 | ⭐⭐⭐ |
| **commit 规范** | Conventional Commits（`feat/fix/docs/chore`） | 项目可维护性 | ⭐⭐ |

### 机器人视觉项目的 Git 实践

```text

├── configs/           ← 实验配置文件

```

| **Hydra** | 分层次的 YAML 配置管理、配置组合和覆盖 | ⭐⭐⭐ |
| **OmegaConf** | Hydra 底层、`from omegaconf import OmegaConf` | ⭐⭐ |
| **配置文件最佳实践** | 训练参数/模型参数/数据参数/部署参数分离 | ⭐⭐⭐ |

### Hydra 配置示例

```yaml
# config.yaml
model:
  name: yolov8
  variant: s          # n/s/m/l/x
  pretrained: True
  num_classes: 80

train:
  epochs: 300
  batch_size: 16
  lr: 0.001
  optimizer: AdamW
  weight_decay: 0.0005

data:
  dataset: COCO
  img_size: 640
  mosaic: 1.0
  mixup: 0.1

deploy:
  engine: tensorrt
  precision: fp16
  dynamic_shape: True
```

### 机器人视觉的测试示例

```python
# test_nms.py
import pytest
import numpy as np
from my_model.postprocess import nms

def test_nms_basic():
    boxes = np.array([[10, 10, 50, 50], [12, 12, 48, 48], [100, 100, 150, 150]])
    scores = np.array([0.9, 0.8, 0.95])
    keep = nms(boxes, scores, iou_threshold=0.5)
    assert len(keep) == 2  # 前两个框高度重叠，应只保留一个
    assert 2 in keep       # 第三个框应保留

def test_nms_empty():
    keep = nms(np.empty((0, 4)), np.empty(0), 0.5)
    assert len(keep) == 0

def test_nms_all_overlap():
    boxes = np.array([[10, 10, 50, 50]] * 5)
    scores = np.array([0.9, 0.8, 0.7, 0.6, 0.5])
    keep = nms(boxes, scores, 0.5)
    assert len(keep) == 1  # 全部重叠，只保留最高分
```
