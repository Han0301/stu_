# 二、数学基础

> **与机器人视觉感知的关联**：数学是机器人视觉的底层语言。**线性代数**描述图像和空间变换，**李群李代数**是 SLAM 位姿优化的核心工具，**卡尔曼滤波**贯穿目标跟踪和传感器融合的全过程，**最优化方法**是 BA 后端求解的基石。数学功底决定了你能在算法层面理解多深，而非仅仅调包。20K 岗位面试中，数学推导是区分"调参侠"和"真懂算法"的关键环节。

## 2.1 线性代数 ⭐⭐⭐

这是 CV 和机器人领域使用最频繁的数学工具，面试中几乎必考。

| 知识点          | 详细内容                 | 与机器人视觉的关联                                               | 掌握程度 |
| ------------ | -------------------- | ------------------------------------------------------- | ---- |
| **矩阵基本运算**   | 矩阵乘法、转置、逆、行列式、秩      | 图像仿射变换矩阵、相机投影矩阵 (3×4)、本质矩阵分解                            | ⭐⭐⭐  |
| **向量空间**     | 线性相关/无关、基、坐标变换、内积/外积 | 相机坐标系与世界坐标系的转换、特征匹配中的描述子距离                              | ⭐⭐⭐  |
| **特征值与特征向量** | 特征分解、对称矩阵的性质         | PCA 降维（特征压缩）、本质矩阵的性质（奇异值模式）                             | ⭐⭐   |
| **SVD 分解**   | 奇异值分解、伪逆计算、低秩近似      | **极重要**：本质矩阵/基础矩阵求解、PnP 中的最小二乘、点云配准的 SVD 解法、单应矩阵分解      | ⭐⭐⭐  |
| **最小二乘**     | OLS、加权最小二乘、正则化（岭回归）  | 相机标定参数优化、PnP 求解、BA 中的重投影误差最小化                           | ⭐⭐⭐  |
| **齐次坐标**     | 齐次表示、无穷远点、仿射变换的齐次形式  | **极重要**：3D 空间变换 (4×4 矩阵)、相机投影 (3×4)、多视图几何中所有计算都在齐次坐标下进行 | ⭐⭐⭐  |

### 必须能手推的公式

```
1. 本质矩阵 E = t^× R，E 的 SVD 分解形式 E = U diag(σ, σ, 0) V^T
2. 从本质矩阵恢复 R,t：4 种解，通过三角化点的正深度选唯一解
3. 旋转矩阵的性质：R^T R = I, det(R) = 1
4. 外积的矩阵形式：a × b = [a]× b，[a]× 是反对称矩阵
```

## 2.2 李群与李代数 ⭐⭐

这是 SLAM 和 3D 视觉中不可或缺的数学工具，也是区分"做 2D CV"和"做机器人 3D 视觉"的知识分水岭。

| 知识点              | 详细内容                              | 与机器人视觉的关联                         | 掌握程度 |
| ---------------- | --------------------------------- | --------------------------------- | ---- |
| **SO(3)**        | 三维旋转群、旋转矩阵的约束                     | 相机姿态（旋转部分）的数学表示                   | ⭐⭐   |
| **SE(3)**        | 三维刚体变换群、4×4 变换矩阵                  | 相机位姿（旋转+平移）的完整表示                  | ⭐⭐   |
| **李代数 so(3)**    | 旋转向量（轴角）、反对称矩阵、指数映射               | **核心**：优化中扰动的紧凑参数化（3 自由度而非 9 自由度） | ⭐⭐⭐  |
| **李代数 se(3)**    | 六维向量（平移+旋转）、指数/对数映射               | SLAM 后端 BA 优化中位姿的增量更新             | ⭐⭐   |
| **指数映射与对数映射**    | Rodriguez 公式、从 so(3) → SO(3) 和反变换 | 旋转矩阵 ←→ 旋转向量的相互转换                 | ⭐⭐⭐  |
| **BCH 公式**       | 李代数的加法与旋转矩阵乘法的近似关系                | **核心**：BA 优化中扰动的叠加方式（左乘/右乘扰动模型）   | ⭐⭐   |
| **伴随矩阵 Adjoint** | SE(3) 的伴随性质                       | 不同坐标系下观测噪声的协方差变换                  | ⭐    |

### 为什么机器人视觉必须学李群李代数？

- 在 SLAM 后端优化中，直接用旋转矩阵 (9 参数) 做优化有**过参数化**问题（必须满足 R^TR=I 约束）
- 李代数将旋转用 3 个参数表示，是**无约束优化**，可用标准高斯-牛顿法
- 面试常见问题：*"为什么要用李代数表示位姿而不是直接优化旋转矩阵？"*

### 必须掌握的工具

- **Sophus 库**：C++ 的 SO(3)/SE(3) 操作库，ORB-SLAM3 和 VINS 都在用
- **`scipy.spatial.transform.Rotation`**：Python 端旋转操作

## 2.3 四元数 ⭐⭐⭐

| 知识点        | 详细内容               | 与机器人视觉的关联                                    | 掌握程度 |
| ---------- | ------------------ | -------------------------------------------- | ---- |
| **四元数定义**  | 实部+虚部、单位四元数、模长     | 紧凑无奇点的姿态表示（比欧拉角优雅，比旋转矩阵少参数）                  | ⭐⭐⭐  |
| **四元数乘法**  | Hamilton 积、不满足交换律  | 旋转的复合（旋转 A 再旋转 B = qB * qA）                  | ⭐⭐⭐  |
| **旋转表示转换** | q ↔ R ↔ 欧拉角 ↔ 旋转向量 | **极重要**：不同场合需要不同表示（ROS 用四元数，可视化用欧拉角，优化用旋转向量） | ⭐⭐⭐  |
| **四元数插值**  | SLERP（球面线性插值）      | 关键帧间位姿插值、IMU 姿态预测                            | ⭐⭐   |
| **四元数求导**  | 四元数对时间的导数、角速度关系    | IMU 运动学方程（四元数微分方程）                           | ⭐⭐   |
| **轴角表示**   | 绕单位向量旋转 θ 角        | 李代数 so(3) 的物理解释、姿态增量的直观表示                    | ⭐⭐   |

### 必须能手写的转换代码

```python
# 四元数 → 旋转矩阵
def quaternion_to_rotation_matrix(q):
    w, x, y, z = q
    R = np.array([[1-2*y*y-2*z*z, 2*x*y-2*w*z, 2*x*z+2*w*y],
                  [2*x*y+2*w*z, 1-2*x*x-2*z*z, 2*y*z-2*w*x],
                  [2*x*z-2*w*y, 2*y*z+2*w*x, 1-2*x*x-2*y*y]])
    return R
```

## 2.4 最优化方法 ⭐⭐

| 知识点          | 详细内容                                     | 与机器人视觉的关联                            | 掌握程度 |
| ------------ | ---------------------------------------- | ------------------------------------ | ---- |
| **梯度下降**     | 批量/SGD/Mini-batch、学习率策略                  | 深度学习训练的基础                            | ⭐⭐   |
| **高斯-牛顿法**   | GN 迭代、Jacobian 矩阵、正规方程 J^T J Δx = -J^T r | **核心**：BA 优化的基础算法                    | ⭐⭐⭐  |
| **LM 算法**    | GN + 阻尼因子 λ、信任区域、Marquardt 方法            | **核心**：SLAM 后端的主流优化器（ceres/g2o 默认使用） | ⭐⭐⭐  |
| **Dogleg**   | LM 的替代方案，结合 GN 和梯度下降                     | 有些 SLAM 系统使用（如 OKVIS）                | ⭐    |
| **鲁棒核函数**    | Huber/L1/ Cauchy 损失函数的导数                 | 抑制外点对 BA 优化的影响                       | ⭐⭐   |
| **Schur 消元** | 利用稀疏性加速 BA 求解、边缘化                        | **核心**：大规模 BA 的高效求解（先消去地图点，再求位姿）     | ⭐⭐   |

### 必须理解的关键概念

```text
BA 优化的本质：
    1. 给定：n 个相机位姿 + m 个 3D 地图点 + 观测（像素坐标）
    2. 残差：重投影误差（观测 - 投影）
    3. 优化：调整位姿和地图点使总重投影误差最小
    4. 求解：LM 算法迭代 J^T J Δx = -J^T r
    5. 加速：利用稀疏性做 Schur 消元（先消地图点，再求位姿）
```

## 2.5 概率论与卡尔曼滤波 ⭐⭐⭐

这是多目标跟踪和多传感器融合的核心理论基础。

| 知识点           | 详细内容                        | 与机器人视觉的关联                          | 掌握程度 |
| ------------- | --------------------------- | ---------------------------------- | ---- |
| **高斯分布**      | 一元/多元高斯、PDF、协方差矩阵、条件分布/边缘分布 | 所有状态估计的基本假设                        | ⭐⭐⭐  |
| **贝叶斯公式**     | 先验/似然/后验、最大后验估计 MAP         | 卡尔曼滤波的理论基础、目标跟踪中的数据关联              | ⭐⭐⭐  |
| **卡尔曼滤波 KF**  | 状态预测 + 观测更新、Kalman Gain 推导  | **极重要**：SORT/DeepSORT 的跟踪核心、IMU 融合 | ⭐⭐⭐  |
| **扩展卡尔曼 EKF** | 非线性系统的线性化、Jacobian 矩阵       | 视觉里程计中的位姿估计（MSCKF）                 | ⭐⭐   |
| **无迹卡尔曼 UKF** | UT 变换、Sigma 点采样             | 强非线性系统（如大角度旋转）的状态估计                | ⭐    |
| **粒子滤波 PF**   | 重要性采样、重采样、SIR 滤波器           | 机器人全局定位（蒙特卡洛定位 MCL）                | ⭐    |

### 必须能手写的一维卡尔曼滤波

```python
class KalmanFilter1D:
    def __init__(self, x0, P0, F, H, Q, R):
        self.x = x0  # 状态估计
        self.P = P0  # 协方差
        self.F = F   # 状态转移矩阵
        self.H = H   # 观测矩阵
        self.Q = Q   # 过程噪声协方差
        self.R = R   # 观测噪声协方差

    def predict(self):
        self.x = self.F @ self.x
        self.P = self.F @ self.P @ self.F.T + self.Q
        return self.x

    def update(self, z):
        y = z - self.H @ self.x          # 残差
        S = self.H @ self.P @ self.H.T + self.R  # 残差协方差
        K = self.P @ self.H.T @ np.linalg.inv(S) # 卡尔曼增益
        self.x = self.x + K @ y          # 状态更新
        self.P = (np.eye(len(self.x)) - K @ self.H) @ self.P  # 协方差更新
        return self.x
```

### 面试常见追问

- KF 的**五大公式**是哪些？（预测两步 + 更新三步）
- **过程噪声 Q 和观测噪声 R** 的含义？怎么调参？（Q 大 = 更相信观测，R 大 = 更相信模型）
- **卡尔曼增益 K** 的物理含义？（权衡预测和观测的可信度）
- KF 为什么假设**高斯分布 + 线性系统**？（高斯经过线性变换仍是高斯，使解析解成为可能）

## 2.6 三维空间刚体几何 ⭐⭐⭐

| 知识点                     | 详细内容                    | 与机器人视觉的关联                                 | 掌握程度            |
| ----------------------- | ----------------------- | ----------------------------------------- | --------------- |
| **刚体变换**                | 旋转 R + 平移 t = SE(3)     | 相机位姿、机器人在世界坐标系的位姿                         | ⭐⭐⭐             |
| **齐次坐标变换**              | 4×4 变换矩阵 T = [R t; 0 1] | **极重要**：链式变换（T_wc = T_wb * T_bc）          | ⭐⭐⭐             |
| **欧拉角**                 | ZYX/YPR 约定、万向锁、旋转顺序     | IMU 姿态输出、ROS RPY 表示、可视化平台                 | ⭐⭐              |
| **旋转向量**                | 轴角表示、Rodriguez 公式       | so(3) 的直观解释                               | ⭐⭐              |
| **欧氏变换/相似变换/仿射变换/射影变换** | 四种变换的自由度与不变量            | 理解不同视觉问题中的变换层次（SLAM 用欧氏，SfM 用相似）          | ⭐⭐              |
| **坐标链**                 | 世界系/相机系/图像系/像素系的转换      | **极重要**：PnP 求解、投影公式 (z * [u,v,1]^T = K [R | t] [X,Y,Z,1]^T) |

### 关键公式：相机投影全链路

```
世界点 Pw = [X, Y, Z, 1]^T
      ↓ 相机外参 [R|t] (世界系→相机系)
相机点 Pc = R*Pw + t
      ↓ 归一化平面
归一化坐标 [x, y, 1]^T = [Xc/Zc, Yc/Zc, 1]^T
      ↓ 相机内参 K (畸变前)
像素坐标 [u, v, 1]^T = K * [x, y, 1]^T
      ↓ 畸变模型
最终像素坐标 (u', v') = 畸变校正( [u, v] )
```

**这个公式必须闭着眼睛也能写出来，面试必考。**
