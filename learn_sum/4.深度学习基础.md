# 四、深度学习基础

> **与机器人视觉感知的关联**：深度学习是现代计算机视觉的引擎。机器人感知系统中的**目标检测、语义分割、深度估计、目标跟踪**等核心功能全部基于深度神经网络。理解深度学习的底层原理（而非只会调 API）决定了你能否对感知模型进行有效的**调试、优化和部署**。20K 岗位要求能独立设计训练 Pipeline、解决训练收敛问题、对模型做精度-速度权衡。

## 4.1 卷积神经网络 CNN ⭐⭐⭐

这是计算机视觉的基石，必须吃透。

| 知识点         | 详细内容                                     | 与机器人视觉的关联                      | 掌握程度 |
| ----------- | ---------------------------------------- | ------------------------------ | ---- |
| **卷积层**     | 卷积核尺寸/步长/padding、输入/输出通道数、参数共享、稀疏连接      | 所有视觉模型的构建单元                    | ⭐⭐⭐  |
| **1×1 卷积**  | 通道升降维、跨通道信息融合、减少参数量                      | MobileNet 和 EfficientNet 的瓶颈设计 | ⭐⭐⭐  |
| **空洞卷积**    | dilation rate、扩大感受野不增加参数量                | 语义分割 DeepLabv3+、小目标检测          | ⭐⭐   |
| **深度可分离卷积** | Depthwise + Pointwise、参数量 = 标准卷积的 1/Cout | 轻量化模型（MobileNet）的核心、边缘端部署标配    | ⭐⭐⭐  |
| **分组卷积**    | 输入/输出通道分组、减少计算量                          | ShuffleNet、ResNeXt             | ⭐⭐   |
| **转置卷积**    | 上采样、反卷积、棋盘格效应                            | 分割网络 decoder 的上采样、GAN 生成       | ⭐    |
| **池化层**     | 最大/平均/全局平均池化、下采样、平移不变性                   | 特征图降维、全局特征聚合（GAP 替代全连接）        | ⭐⭐   |
| **全连接层**    | 线性层 + 激活、参数量大                            | 分类头（检测和分类模型的输出层）               | ⭐⭐   |

### 卷积参数量与 FLOPs 计算（面试手撕题）

```
输入: H×W×Cin, 卷积核: K×K, 输出: H'×W'×Cout
参数量 = K × K × Cin × Cout         (不含 bias 时)
               + Cout                (含 bias 时)
计算量 FLOPs = K × K × Cin × H' × W' × Cout × 2   (乘加各算 1 FLOP)
```

### 感受野计算（面试高频）

```
从顶层反向递推: RF_{l-1} = (RF_l - 1) × stride_l + kernel_l

或正向递推: RF_l = RF_{l-1} + (kernel_l - 1) × ∏_{i=1}^{l-1} stride_i
```

## 4.3 归一化技术 ⭐⭐⭐

面试最常被追问的板块之一。

| 知识点              | 详细内容                                                         | 与机器人视觉的关联                                            | 掌握程度 |
| ---------------- | ------------------------------------------------------------ | ---------------------------------------------------- | ---- |
| **BatchNorm**    | 按 Batch 维度归一化、可学习 γ/β、训练/推理模式差异                              | **默认标配**：加速收敛、缓解梯度弥散、有正则化效果                          | ⭐⭐⭐  |
| **LayerNorm**    | 按特征维度归一化、不受 batch size 限制                                    | **Transformer 标配**（ViT/DETR/Swin Transformer 全部用 LN） | ⭐⭐⭐  |
| **InstanceNorm** | 按单样本单通道归一化                                                   | 图像风格迁移、GAN 生成                                        | ⭐    |
| **GroupNorm**    | 介于 LN 和 IN 之间、分组归一化                                          | 小 batch size 时 BN 失效的替代（检测模型常用）                      | ⭐⭐⭐  |
| **BN 的推理细节**     | `running_mean/running_var`、`track_running_stats`、`eval()` 模式 | **必须理解**：训练和推理行为不同，部署时需合并到 Conv 中                    | ⭐⭐⭐  |
| **BN 合并**        | Conv + BN → 单一 Conv 层（推理加速）                                  | TensorRT 自动做、手写部署时需自己实现                              | ⭐⭐⭐  |

### 面试必问题

- **为什么 BN 能加速训练？**（缓解 internal covariate shift / 平滑损失景观）
- **为什么 BN 在 batch size 很小时效果差？**（统计量估计不准 → 噪声大）
- **LN 和 BN 的根本区别？**（归一化维度不同：BN 归一化特征通道，LN 归一化样本特征）
- **检测模型中常用 GN 而非 BN？**（检测模型训练常用大分辨率图像，batch size 小）

## 4.4 损失函数 ⭐⭐⭐

| 知识点                               | 详细内容                            | 与机器人视觉的关联                        | 掌握程度 |
| --------------------------------- | ------------------------------- | -------------------------------- | ---- |
| **Cross-Entropy Loss**            | 分类损失、软标签（Label Smoothing）       | 分类任务的标准损失                        | ⭐⭐⭐  |
| **BCE Loss**                      | 二分类交叉熵、`with_logits` 参数         | 多标签分类、检测的分类分支                    | ⭐⭐⭐  |
| **Focal Loss**                    | `-α(1-p)^γ log(p)`、难易样本平衡       | **目标检测**：解决正负样本/难易样本不均衡          | ⭐⭐⭐  |
| **Smooth L1 Loss**                | L1/L2 混合、梯度不过大                  | **目标检测**：边界框回归的标准损失              | ⭐⭐⭐  |
| **IoU Loss / GIoU / DIoU / CIoU** | 直接优化 IoU、解决 L1 与 IoU 不对齐问题      | **检测 BBox 回归**：现代检测器全部用 IoU 系列损失 | ⭐⭐⭐  |
| **Dice Loss**                     | 2                               | A∩B                              | /(   |
| **Triplet Loss**                  | anchor/positive/negative、margin | 行人重识别 ReID、人脸识别、跟踪 ReID          | ⭐⭐   |
| **Contrastive Loss**              | 相似样本靠近、不相似样本远离                  | 自监督学习、表征学习                       | ⭐⭐   |

### 检测模型损失函数组合（必须了解）

```
YOLOv8 的损失 = 分类 BCE Loss + 回归 CIoU Loss + DFL Loss
                                    ↓
  分类分支: 每个类别独立的二分类 (BCE)
  回归分支: 分布聚焦损失 DFL (Distribution Focal Loss) + CIoU
  为什么用 DFL? 让模型学习边界的不确定性分布
```

## 4.5 优化器与学习率策略

| 知识点         | 详细内容                                           | 与机器人视觉的关联                      | 掌握程度 |
| ----------- | ---------------------------------------------- | ------------------------------ | ---- |
| **SGD**     | 标准 SGD、SGD+Momentum（物理动量）                      | 通用优化器，某些场景泛化性好                 | ⭐⭐   |
| **Adam**    | 自适应学习率、一阶/二阶动量估计                               | **最常用**：快速收敛、超参数鲁棒             | ⭐⭐⭐  |
| **AdamW**   | Adam + 解耦权重衰减                                  | 比 Adam 正则化效果更好，ViT 训练标配        | ⭐⭐⭐  |
| **余弦退火**    | `η_t = η_min + 0.5(η_max-η_min)(1+cos(t/T·π))` | 检测模型训练的默认策略                    | ⭐⭐⭐  |
| **Warm-up** | 前 k 步学习率从 0 线性升到目标值                            | 稳定训练初期（大 batch 训练必需）           | ⭐⭐⭐  |
| **梯度裁剪**    | `torch.nn.utils.clip_grad_norm_`               | 防止梯度爆炸（稳定训练）                   | ⭐⭐   |
| **EMA**     | 指数移动平均模型参数                                     | **检测模型常用**：推理时用 EMA 权重比当前权重更鲁棒 | ⭐⭐⭐  |

### 训练食谱（Training Recipe）示例

```yaml
# YOLOv8 训练配置
optimizer: AdamW
lr: 0.001
weight_decay: 0.0005
lr_schedule:
  warmup_epochs: 3
  warmup_momentum: 0.8
  warmup_bias_lr: 0.1
  cos_lr: True
  lrf: 0.01  # 最终学习率 = lr * lrf
ema: True
ema_decay: 0.9999
amp: True  # 混合精度训练
```

## 4.6 数据增强 ⭐⭐⭐

在机器人视觉中，数据增强直接决定模型在复杂光照/视角下的泛化能力。

| 知识点                | 详细内容                                   | 与机器人视觉的关联                       | 掌握程度 |
| ------------------ | -------------------------------------- | ------------------------------- | ---- |
| **几何增强**           | 随机翻转/旋转/缩放/裁剪/仿射                       | **检测/分割必备**：模拟不同视角              | ⭐⭐⭐  |
| **颜色增强**           | 亮度/对比度/饱和度/色相抖动                        | 适应不同光照条件（户外光线变化大）               | ⭐⭐⭐  |
| **MixUp**          | 两张图按比例混合、标签也混合                         | 正则化、提升泛化                        | ⭐⭐   |
| **Mosaic**         | 四张图拼成一张、BN 统计量更丰富                      | **YOLO 系列标配**：小目标检测效果好          | ⭐⭐⭐  |
| **CutMix**         | 一块区域用另一张图替换                            | 分类/检测的强增强                       | ⭐⭐   |
| **Albumentations** | 高效的图像增强库（50+ 种增强）                      | **工业界标配**：比 torchvision 快、增强花样多 | ⭐⭐⭐  |
| **Copy-Paste**     | 将目标复制粘贴到其他图上                           | 小样本/不均衡类别的增强                    | ⭐    |
| **自动增强**           | AutoAugment、RandAugment、TrivialAugment | 免去手动调增强策略                       | ⭐    |

### 训练精度调试 checklist

```
□ loss 是否在合理范围？（分类 ~2-3 → 0.0x, 回归 ~0.1-0.01）
□ 验证集 mAP 是否随训练上升？（不是 → 检查数据/标签/增强）
□ 是否过拟合？（训练 loss 降但验证 loss 升 → 加正则/增强）
□ BN 是否训练正确？（eval 模式效果大降 → running stats 问题）
□ 学习率是否合适？（loss 震荡 → lr 太大；loss 不降 → lr 太小/warmup 问题）
□ 梯度是否正常？（梯度爆炸 → 加 grad clip；梯度消失 → 检查 BN 和激活）
```

### 4.9.2 FPN 特征金字塔（检测必备）⭐⭐⭐

| 结构          | 核心思想                    | 用途             |
| ----------- | ----------------------- | -------------- |
| **FPN**     | 自顶向下 + 侧向连接，融合深层语义+浅层细节 | 所有检测器的 Neck 基础 |
| **PANet**   | FPN + 自底向上路径            | YOLOv8 的 Neck  |
| **BiFPN**   | 加权融合、跨尺度连接              | EfficientDet   |
| **NAS-FPN** | NAS 搜索的 FPN 结构          | —              |

### 必须理解的 FPN 机制

```
输入: C3/C4/C5 (Backbone 的 3 层输出)
    ↓ 自顶向下
P5 = Conv(C5)                 # 顶层语义最强
P4 = Conv(C4) + Upsample(P5)   # 融合细节
P3 = Conv(C3) + Upsample(P4)   # 底层细节最多
    ↓
三尺度输出 P3/P4/P5，分别检测大/中/小目标
```

### PyTorch 训练模板（必须能不查文档写出来）

```python
class Trainer:
    def __init__(self, model, train_loader, optimizer, device):
        self.model = model.to(device)
        self.train_loader = train_loader
        self.optimizer = optimizer
        self.device = device
        self.scaler = torch.cuda.amp.GradScaler()

    def train_epoch(self):
        self.model.train()
        for batch_idx, (images, targets) in enumerate(self.train_loader):
            images = images.to(self.device)
            targets = [{k: v.to(self.device) for k, v in t.items()} for t in targets]

            with torch.cuda.amp.autocast():
                loss_dict = self.model(images, targets)
                loss = sum(loss_dict.values())

            self.scaler.scale(loss).backward()
            self.scaler.unscale_(self.optimizer)
            torch.nn.utils.clip_grad_norm_(self.model.parameters(), max_norm=10.0)

            self.scaler.step(self.optimizer)
            self.scaler.update()
            self.optimizer.zero_grad()

            if batch_idx % 10 == 0:
                print(f'Batch {batch_idx}: { {k: v.item() for k, v in loss_dict.items()} }')
```
