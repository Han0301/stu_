# 三、数字图像处理

> **与机器人视觉感知的关联**：数字图像处理是计算机视觉的"底层设施"。机器人从摄像头获取的原始图像需要经过预处理才能送入深度学习模型，后处理也需要图像处理技术来解析结果。虽然深度学习时代很多传统手工特征被替代，但**图像滤波、几何变换、边缘检测**等基础操作仍然是每一个 CV 算法工程师的日常工具。此外，**相机标定**和**图像畸变校正**在机器人视觉中是必知必会的技能。

## 3.1 像素与色彩空间

| 知识点           | 详细内容                                       | 与机器人视觉的关联                                               | 掌握程度 |
| ------------- | ------------------------------------------ | ------------------------------------------------------- | ---- |
| **像素表示**      | 灰度图 / RGB / BGR / RGBA / 二值图               | OpenCV 默认 BGR（与 RGB 不同，必须牢记）                            | ⭐⭐⭐  |
| **BGR ↔ RGB** | `cv2.cvtColor(img, cv2.COLOR_BGR2RGB)`     | **极重要**：绝大多数深度学习模型在 RGB 预训练，OpenCV 读入为 BGR，不改会出**静默错误** | ⭐⭐⭐  |
| **YUV/YCbCr** | 亮度-色度分离表示                                  | 视频压缩、某些 ISP 输出格式                                        | ⭐    |
| **HSV/HSL**   | 色相/饱和度/明度，与 RGB 的转换                        | 基于颜色的目标分割（如车道线/交通灯检测的预处理）                               | ⭐⭐   |
| **位深度**       | uint8 / uint16 / float32、归一化 (0-255 → 0-1) | 模型输入必须归一化，精度影响推理效果                                      | ⭐⭐⭐  |

### 常见陷阱

```python
# ❌ 错误：OpenCV 读入直接显示
img = cv2.imread('image.jpg')
plt.imshow(img)  # 颜色偏蓝（BGR 被当成 RGB 显示）

# ✅ 正确
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
plt.imshow(img_rgb)

# ✅ 模型推理时的预处理
img = cv2.imread('image.jpg')
img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
img = img.astype(np.float32) / 255.0
img = (img - mean) / std  # 归一化
```

## 3.2 图像滤波与去噪

| 知识点         | 详细内容                            | 与机器人视觉的关联                 | 掌握程度 |
| ----------- | ------------------------------- | ------------------------- | ---- |
| **均值滤波**    | 方框滤波、核内取平均、O(n²k²)              | 简单去噪（会模糊边缘）               | ⭐    |
| **高斯滤波**    | 高斯核 σ 控制平滑程度、`cv2.GaussianBlur` | **预处理标配**：减少图像噪声对特征提取的影响  | ⭐⭐⭐  |
| **中值滤波**    | 核内取中位数、对椒盐噪声效果极好                | 去除摄像头传输出错的坏点              | ⭐⭐   |
| **双边滤波**    | 空间+值域双权重、保边去噪                   | 需要保留边缘同时去噪的场景（SLAM 前端预处理） | ⭐⭐   |
| **非局部均值去噪** | `cv2.fastNlMeansDenoising`      | 低光照图像的增强（夜间机器人视觉）         | ⭐    |

### 在机器人视觉 Pipeline 中的位置

```
摄像头捕获原始图像
      ↓
 去畸变（相机标定参数）
      ↓
 高斯滤波（轻度去噪）
      ↓
 缩放 + 归一化 → 送入深度学习模型
```

## 3.3 边缘检测

| 知识点              | 详细内容                         | 与机器人视觉的关联                       | 掌握程度 |
| ---------------- | ---------------------------- | ------------------------------- | ---- |
| **Sobel 算子**     | 一阶导数近似、水平/垂直边缘               | 传统特征提取的梯度计算                     | ⭐⭐   |
| **Laplacian 算子** | 二阶导数、对噪声敏感                   | 图像锐化、边缘增强                       | ⭐    |
| **Canny 边缘检测**   | 四步：高斯平滑 → 梯度幅值 → NMS → 双阈值滞后 | **经典算法**：传统 SLAM 中 ORB 特征提取的预处理 | ⭐⭐⭐  |
| **Canny 参数调优**   | 高/低阈值比例 2:1~3:1、σ 自适应        | 不同光照条件下获得一致的边缘响应                | ⭐⭐   |

### Canny 四步详解（面试常问）

```
Step 1: 高斯滤波平滑图像，σ 控制去噪强度
Step 2: Sobel 计算梯度幅值 G = √(Gx²+Gy²) 和方向 θ = arctan(Gy/Gx)
Step 3: 非极大值抑制 NMS — 沿梯度方向保留局部最大值（细化边缘）
Step 4: 双阈值检测 — 高阈值确定强边缘，低阈值连接弱边缘（滞后阈值）
```

## 3.4 几何变换 ⭐⭐⭐

这是图像预处理和后处理中最频繁使用的技能。

| 知识点      | 详细内容                                       | 与机器人视觉的关联                                | 掌握程度 |
| -------- | ------------------------------------------ | ---------------------------------------- | ---- |
| **图像缩放** | 插值方法：最近邻/双线性/双三次/Lanczos                   | 模型输入尺寸固定，必须缩放（注意宽高比处理方式）                 | ⭐⭐⭐  |
| **图像平移** | 平移矩阵、`cv2.warpAffine`                      | ROI 区域对齐、图像稳定                            | ⭐⭐   |
| **图像旋转** | 旋转矩阵、旋转中心、缩放因子                             | 数据增强、倾斜校正                                | ⭐⭐   |
| **仿射变换** | 2×3 矩阵、6 自由度、平行线不变                         | 图像配准、数据增强（随机仿射）、**YOLO 的 Mosaic 增强**     | ⭐⭐⭐  |
| **透视变换** | 3×3 矩阵、8 自由度、`cv2.getPerspectiveTransform` | **BEV 转换**（鸟瞰图）、文档校正、**自动驾驶的 IPM 逆透视映射** | ⭐⭐⭐  |
| **图像拼接** | 特征匹配 + 单应矩阵 + 融合                           | 全景图、大场景建图                                | ⭐    |

### 透视变换在 BEV 感知中的关键作用

```python
# 计算机器人前方的 BEV 鸟瞰图
# 1. 选取图像中四个点（如车道线的四边形）
src_pts = np.array([[x1,y1], [x2,y2], [x3,y3], [x4,y4]], dtype=np.float32)
# 2. 定义 BEV 中对应的矩形位置
dst_pts = np.array([[0,0], [w,0], [w,h], [0,h]], dtype=np.float32)
# 3. 计算透视变换矩阵
M = cv2.getPerspectiveTransform(src_pts, dst_pts)
# 4. 应用变换
bev = cv2.warpPerspective(img, M, (w, h))
```

## 3.8 相机标定 ⭐⭐⭐

**机器人视觉感知中必须亲手做一次的实践**。

| 知识点        | 详细内容                                                          | 与机器人视觉的关联                               | 掌握程度 |
| ---------- | ------------------------------------------------------------- | --------------------------------------- | ---- |
| **张正友标定法** | 棋盘格 + 已知角点 → 求解内参 + 畸变系数                                      | **极重要**：获取相机内参 K 和畸变参数 (k1,k2,p1,p2,k3) | ⭐⭐⭐  |
| **内参矩阵 K** | `[fx, 0, cx; 0, fy, cy; 0, 0, 1]`                             | 投影公式的核心，所有 3D-2D 转换的桥梁                  | ⭐⭐⭐  |
| **畸变校正**   | `cv2.undistort` / `cv2.initUndistortRectifyMap`               | 去畸变是预处理的第一步，不做畸变校正特征匹配会出错               | ⭐⭐⭐  |
| **投影矩阵 P** | K[R\|t]                                                       | 已知 3D 点计算像素坐标                           | ⭐⭐⭐  |
| **重投影误差**  | 标定质量的评估指标                                                     | 验证标定效果                                  | ⭐⭐   |
| **标定工具**   | MATLAB Camera Calibrator、OpenCV `calibrateCamera`、Kalibr（ROS） | 日常标定实操                                  | ⭐⭐⭐  |

### 标定实操步骤

```
1. 打印棋盘格（建议 8×6 内角点，方格 30mm）
2. 手持棋盘格在相机前平移/旋转/倾斜，拍摄 15-20 张
3. OpenCV findChessboardCorners → calibrateCamera
4. 检查重投影误差 < 0.5 pixel
5. 保存内参 K 和畸变系数到 YAML
6. 验证：拍摄一张图像 → undistort → 直线不再弯曲
```
