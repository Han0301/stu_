# 2.2.5 se(3) 与伴随矩阵

> **机器人视觉定位**：se(3) 是 SE(3) 对应的李代数，它用一个**六维向量**同时表示旋转和平移的增量。这是 SLAM 后端 BA 优化中**位姿更新的标准形式**。而**伴随矩阵**解决了"同一个物理量在不同坐标系下如何变换"的问题——在多传感器融合中至关重要。

---

## 1. se(3) 的定义

### 1.1 se(3) 的矩阵形式

se(3) 中的元素是 4×4 矩阵：

    ξ^∧ = [ϕ^∧, ρ; 0, 0] ∈ ℝ⁴ˣ⁴

其中：
- `ϕ ∈ ℝ³`：旋转分量（对应 so(3)）
- `ρ ∈ ℝ³`：平移分量
- `ξ = [ρ, ϕ]^T ∈ ℝ⁶`：se(3) 的向量形式（六维向量）

```python
def hat_se3(xi):
    """
    se(3) wedge 操作：六维向量 → 4×4 矩阵
    xi: (6,) [ρ_x, ρ_y, ρ_z, ϕ_x, ϕ_y, ϕ_z]
    """
    rho, phi = xi[:3], xi[3:]
    Xi = np.zeros((4, 4))
    Xi[:3, :3] = hat(phi)     # 左上：ϕ^∧
    Xi[:3, 3] = rho           # 右上：ρ
    return Xi

def vee_se3(Xi):
    """se(3) vee 操作：4×4 矩阵 → 六维向量"""
    rho = Xi[:3, 3]
    phi = vee(Xi[:3, :3])
    return np.hstack([rho, phi])
```

### 1.2 se(3) 的自由度

| 参数 | 旋转 | 平移 | 合计 |
|------|------|------|------|
| SO(3) | 3 | — | 3 |
| SE(3) | 3 | 3 | **6** |
| so(3) | 3 | — | 3 |
| **se(3)** | 3 | 3 | **6** |

## 2. se(3) 的指数映射

### 2.1 完整公式

给定 se(3) 中的元素 `ξ = [ρ, ϕ]^T`，指数映射得到 SE(3)：

```
exp(ξ^∧) = [R, t; 0, 1]
```
（se(3) 指数映射的完整形式；`R` 是 Rodriguez 公式计算的旋转矩阵，`t` 是 V 矩阵乘以平移分量 `ρ` 得到的平移向量）
```
R = exp(ϕ^∧)                （Rodriguez 公式）
t = V(ϕ) · ρ                （V 矩阵乘以平移分量）
```

**V 矩阵**（平移部分的系数矩阵）：

    V(ϕ) = E + (1 - cosθ)/θ · n^∧ + (θ - sinθ)/θ · (n^∧)²

```python
def V_matrix(phi):
    """se(3) 指数映射中的 V 矩阵"""
    theta = np.linalg.norm(phi)
    if theta < 1e-10:
        return np.eye(3)
    n = phi / theta
    n_hat = hat(n)
    
    V = (np.eye(3) 
         + (1 - np.cos(theta)) / theta * n_hat 
         + (theta - np.sin(theta)) / theta * (n_hat @ n_hat))
    return V
```

### 2.2 在 BA 中的实际应用

```python
def update_pose_se3(T, delta_xi):
    """
    BA 中位姿的增量更新
    T: (4,4) 当前位姿 ∈ SE(3)
    delta_xi: (6,) 增量 ∈ se(3)
    """
    rho, phi = delta_xi[:3], delta_xi[3:]
    
    R = exp_so3(phi)
    V = V_matrix(phi)
    t = V @ rho
    
    # 构造增量矩阵
    delta_T = np.eye(4)
    delta_T[:3, :3] = R
    delta_T[:3, 3] = t
    
    # 右乘更新（也可左乘）
    T_new = T @ delta_T
    return T_new
```

## 3. 伴随矩阵 ⭐

### 3.1 核心问题

在机器人视觉中，我们经常需要在不同坐标系之间变换观测量的**不确定性**（协方差矩阵）。

```
相机系中的观测噪声 Σ_c
    ↓ 伴随变换
世界系中的噪声 Σ_w = Ad(T) · Σ_c · Ad(T)^T
```

### 3.2 SE(3) 的伴随矩阵

**伴随矩阵** `Ad(T)` 描述了 SE(3) 元素在切线空间（se(3)）上的线性变换：

    Ad(T) = [R, t^∧·R; 0, R] ∈ ℝ⁶ˣ⁶
（SE(3) 的伴随矩阵，6×6；`R` 是旋转矩阵，`t` 是平移向量，`t^∧` 是 `t` 的反对称矩阵；用于 se(3) 上向量和协方差的坐标系变换）

```python
def adjoint(T):
    """
    SE(3) 的伴随矩阵 Ad(T)
    T: (4,4) 变换矩阵
    return: (6,6) 伴随矩阵
    """
    R = T[:3, :3]
    t = T[:3, 3]
    t_hat = hat(t)
    
    Ad = np.zeros((6, 6))
    Ad[:3, :3] = R
    Ad[3:, 3:] = R
    Ad[:3, 3:] = t_hat @ R
    return Ad
```

### 3.3 伴随矩阵的性质

| 性质 | 公式 | 含义 |
|------|------|------|
| **线性性** | Ad(T₁·T₂) = Ad(T₁) · Ad(T₂) | 伴随变换保持复合结构 |
| **可逆性** | Ad(T⁻¹) = Ad(T)⁻¹ | 逆变换的伴随 |
| **协方差变换** | Σ' = Ad(T) · Σ · Ad(T)ᵀ | 噪声协方差的坐标系变换 |

### 3.4 协方差变换的应用

```python
def transform_covariance(T, Sigma):
    """
    将 se(3) 上的协方差矩阵从一个坐标系变换到另一个
    T: (4,4) 坐标系变换
    Sigma: (6,6) 原坐标系下的协方差
    """
    Ad = adjoint(T)
    Sigma_transformed = Ad @ Sigma @ Ad.T
    return Sigma_transformed

# 示例：将相机系下的位姿不确定性变换到世界系
T_wc = np.eye(4)  # 相机在世界系下的位姿
T_wc[:3, :3] = exp_so3(np.array([0.1, 0.2, 0.3]))
T_wc[:3, 3] = np.array([1.0, 2.0, 3.0])

# 相机系下的协方差（假设各向同性）
Sigma_c = np.eye(6) * 0.01

# 变换到世界系
Sigma_w = transform_covariance(T_wc, Sigma_c)
print("世界系下的协方差:\n", Sigma_w)
```

## 4. se(3) 扰动模型的 Jacobian

在 BA 中，我们需要误差对 se(3) 扰动的 Jacobian：

```python
def jacobian_se3_point(T, P):
    """
    3D 点 P 经过 T 变换后，对 se(3) 扰动的 Jacobian
    T: (4,4) 当前位姿
    P: (3,) 世界坐标系下的 3D 点
    return: (3,6) Jacobian
    """
    # 变换后的点
    P_c = T[:3, :3] @ P + T[:3, 3]
    
    # ∂P_c / ∂Δξ = [E, -P_c^∧]
    J = np.hstack([np.eye(3), -hat(P_c)])
    return J
```

这个 3×6 的 Jacobian 是 BA 优化中的核心组成部分。结合重投影误差的导数（2×3），就得到了完整的 2×6 BA Jacobian。

## 必须掌握的核心要点

1. **se(3) 的六维参数**：[ρ, ϕ]——平移和旋转的增量
2. **se(3) 指数映射**：旋转用 Rodriguez，平移用 V 矩阵
3. **伴随矩阵 Ad(T)**：`[R, t^∧R; 0, R]`——协方差和误差的坐标系变换
4. **se(3) 扰动 Jacobian**：`∂P'/∂Δξ = [E, -P'^∧]`（BA 优化的基础）
5. **协方差变换**：Σ' = Ad(T)·Σ·Ad(T)ᵀ（多传感器融合中常用）
